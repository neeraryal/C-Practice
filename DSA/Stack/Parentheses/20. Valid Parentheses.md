# 20. Valid Parentheses
> `()[]{}` wali string mein har bracket sahi type se aur sahi order mein band hua hai ya nahi — check karo

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Parentheses – real stack + closing→opening map](parentheses.md) | `stack<char>` + `unordered_map<char,char>` | O(n) | O(n) |

**How it works**
- **Soch:** 3 types hain → sirf count se kaam nahi chalega (`"([)]"` mein counts barabar hain par invalid). Yaad rakhna padega **kaunsa** bracket sabse last khula tha → stack (LIFO: last open, first close).
- **Push:** Opening bracket → `st.push(c)`.
- **Match:** Closing bracket → stack khaali ho ya `st.top() != mapp[c]` (top pe iska opening nahi) → `false`. Warna `pop()`.
- **End:** `return st.empty()` → koi opening bina band hue bacha to invalid.
- **Kyun sahi hai:** Har closing ko sabse recent unmatched opening se hi match hona chahiye — stack top exactly wahi hai. Ek pass → O(n), worst case saare openings stack mein → O(n) space.
- **Dry run:** `"([)]"`
  - `(`, `[` push → stack `( [`
  - `)`: top `[` != `mapp[')']` = `(` → `false` ✔
- **Approach 2/3:** `/* */` block mein do purane versions — Approach 2: `while` loop + `switch` se har closing type ka alag case (map ki jagah hardcoded match); Approach 3: main jaisa hi (map + stack), bas index loop `s[i]` se.

**Gotcha:** `st.empty()` check `||` mein **pehle** — warna `")"` pe empty stack ka `top()` UB. Loop ke baad `st.empty()` zaroori (`"(("` → false). Approach 2 mein `||` ki jagah bitwise `|` hai — bools pe sahi result deta hai (short-circuit nahi), bas nit.
**vs related:** [1614](<1614. Maximum Nesting Depth of the Parentheses.md>) / [1021](<1021. Remove Outermost Parentheses.md>) mein ek type + valid input guaranteed → counter kaafi tha. Yahan types mix + invalid input → real stack.

## Code

```cpp
class Solution {
public:
    bool isValid(string s) 
    {
        unordered_map<char,char> mapp= {{'}','{'},{']','['},{')','('}};  // closing → uska opening; match check ek lookup mein
        stack<char>st;  // unmatched openings; top = sabse recent khula bracket

        for(auto &c : s)
        {
            if(c=='(' || c == '{' || c == '[')  // opening → push, baad mein closing se match hoga
                st.push(c);
            else
            {
                if(st.empty() || st.top() != mapp[c]) return false;  // closing: koi open nahi ya top pe galat type → invalid
                st.pop();  // match ho gaya → wo opening band
            }
        }
        return st.empty();  // opening bacha → kabhi band nahi hua → false
    }
};
```
