# 1614. Maximum Nesting Depth of the Parentheses
> Valid parentheses string mein maximum nesting depth do (kitne `(` ek ke andar ek khule hain)

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Parentheses – counter as implicit stack](parentheses.md) | `int open_count` (stack ka size) | O(n) | O(1) |

**How it works**
- **Soch:** Stack se karte to har `(` push, har `)` pop — aur depth = stack ka size. Ek hi bracket type hai aur string valid hai, to stack ke andar kya hai matter hi nahi karta → sirf size chahiye → ek counter kaafi.
- **Track:** `(` pe `open_count++`, `)` pe `open_count--`; digits/operators ignore.
- **Record:** Har char ke baad `res = max(res, open_count)` → depth ka peak.
- **Kyun sahi hai:** Kisi bhi point pe depth = ab tak khule par band na hue `(` ki ginti = `open_count`. Max over time hi answer. Ek pass → O(n), O(1).
- **Dry run:** `"(1+(2*3)+((8)/4))+1"`
  - `(1+(` → open_count 2
  - `2*3)` → wapas 1
  - `+((8` → 3 → `res=3`
  - baaki sab band → 0, `res=3` ✔

**Gotcha:** Counter tabhi kaafi hai jab ek hi bracket type ho aur input valid ho (yahan guaranteed) — invalid input pe `open_count` negative jaa sakta hai.
**vs related:** [1021](<1021. Remove Outermost Parentheses.md>) mein same counter hai, par wahan `open_count == 0` wala moment kaam aata hai (primitive khatam). [20](<20. Valid Parentheses.md>) mein 3 types → counter fail, real stack chahiye.

## Code

```cpp
class Solution {
public:
    int maxDepth(string s) {
        int res=0;
        int open_count=0;  // khule '(' ki ginti = implicit stack size = current depth
        for ( auto & ch : s)
        {
            if (ch=='(')
            {
                open_count++;  // push: ek level andar
            }
            else if(ch==')')
            {
                open_count--;  // pop: ek level bahar (valid string → kabhi -ve nahi)
            }
            res=max(res,open_count);  // record answer: depth ka peak
        }
        return res;
    }
};
```
