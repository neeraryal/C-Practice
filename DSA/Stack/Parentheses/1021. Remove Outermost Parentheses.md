# 1021. Remove Outermost Parentheses
> Valid parentheses string ko primitive parts mein todo aur har part ke sabse bahar wale `(` `)` hata do

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Parentheses – counter, zero = primitive end](parentheses.md) | `int open_count` + `left` / `right` indices | O(n) | O(1) extra (output alag) |

**How it works**
- **Soch:** Primitive = wo sabse chhota balanced block jahan counter 0 se shuru hoke pehli baar wapas 0 pe aata hai. Outer bracket hatana = us block ka andar wala part `s[left+1 .. right-1]` copy karna.
- **Track:** `right` har char pe aage; `(` pe `open_count++`, `)` pe `open_count--`.
- **Cut:** `open_count == 0` → primitive `s[left..right]` poora → `res.append(s, left+1, right-left-1)`, phir `left = right+1` (agle primitive ka start).
- **Kyun sahi hai:** Valid string mein counter kabhi negative nahi hota aur 0 pe tabhi aata hai jab ek balanced block band hua — yahi primitive boundary hai. Har char ek baar → O(n).
- **Dry run:** `"(()())(())"`
  - `right=5`: counter 0 → primitive `(()())` → append `()()`, `left=6`
  - `right=9`: counter 0 → primitive `(())` → append `()`
  - `res = "()()()"` ✔

**Gotcha:** `append(s, pos, len)` ka 3rd argument **length** hai, end index nahi → `right-left-1`. `"()"` primitive pe length 0 → kuch append nahi (Example 3 → `""`).
**vs related:** [1614](<1614. Maximum Nesting Depth of the Parentheses.md>) mein counter ka max chahiye tha; yahan counter ka **0 hona** event hai. [20](<20. Valid Parentheses.md>) mein 3 bracket types → counter nahi, real stack.

## Code

```cpp
class Solution {
public:
    string removeOuterParentheses(string s) 
    {
        string res ="";
        int left = 0, right = 0;  // left = current primitive ka start, right = scan pointer
        int open_count=0;
        while(right<s.size())
        {
            if(s[right]=='(')
                open_count++;  // '(' → ek level andar
            else
                open_count--;  // ')' → ek level bahar (valid string → kabhi -ve nahi)

            if(open_count ==0)  // counter wapas 0 → primitive s[left..right] poora hua
            {
                res.append(s,left+1, right-left-1);  // outer ( ) chhod ke andar ka part: pos left+1, length right-left-1
                left=right+1;  // agla primitive yahin se shuru
            }
            right++;
        }
        return res;
    }
};
```
