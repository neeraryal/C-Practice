# 977. Squares of a Sorted Array
> Sorted array (negatives bhi) ke squares sorted order mein return karo

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Two Pointers – opposite ends, fill from back](two_pointers.md) | `calloc` result array | O(n) | O(1) extra (output alag) |

**How it works**
- **Soch:** Negatives ki wajah se squares sorted nahi rehte, lekin sabse bada square hamesha kisi ek **end** pe hota hai (sabse negative ya sabse positive). To dono ends compare karo aur bada square result ke **peeche** se bharo.
- **Move (Solution 2):** `abs(arr[left]) > abs(arr[right])` → `res[index--] = arr[left]²`, `left++`. Warna `arr[right]²`, `right--`.
- **Approach 1:** Pehla non-negative index dhoondho (split point). Wahan se `left_index` peeche aur `i` aage — dono taraf squares badhte hain → merge sort ka merge step (chhota square pehle), phir jo half bacha uske squares copy.
- **Kyun sahi hai:** Har step baaki elements mein se sabse bada square place hota hai, isliye peeche se bharna sorted deta hai. `left <= right` taaki beech wala last element bhi aaye. O(n).
- **Dry run:** `[-4,-1,0,3,10]`
  - `4 < 10` → `res[4]=100`, `right=3`
  - `4 > 3` → `res[3]=16`, `left=1`
  - `1 < 3` → `res[2]=9`; `1 > 0` → `res[1]=1`; `left=right=2` → `res[0]=0` → `[0,1,9,16,100]` ✔

**Gotcha:** Dono solutions ka naam `sortedSquares` hai → ek file mein saath compile nahi honge, ek hi rakho. Solution 1 mein `calloc(n, sizeof(arr))` — `sizeof(arr)` pointer ka size (8) hai, `int` (4) nahi → double memory; output sahi, bas waste.
**vs related:** [11](<11.Container With Most Water.md>) bhi opposite ends se chalta hai, par wahan greedy "chhoti side hatao". [167](<../Two_Sum/167. Two Sum II - Input Array Is Sorted.md>) opposite pointers + sum compare.

<details><summary>Problem statement</summary>

Given an integer array nums sorted in non-decreasing order, return an array of the squares of each number sorted in non-decreasing order.

 

Example 1:

Input: nums = [-4,-1,0,3,10]
Output: [0,1,9,16,100]
Explanation: After squaring, the array becomes [16,1,0,9,100].
After sorting, it becomes [0,1,9,16,100].
Example 2:

Input: nums = [-7,-3,2,3,11]
Output: [4,9,9,49,121]

</details>

## Code

```c
/* =========================
    Solution 1 by using 2 pointer and splitting array 
   ========================= */

int* sortedSquares(int* arr, int n, int* returnSize) 
{
    int left_index=0,i=0;
    while(left_index<n && arr[left_index]<0){left_index++;}  // split point: pehla non-negative index
    i=left_index;  // i → non-negatives, aage jaate squares badhte hain
    left_index-=1;  // left_index → last negative, peeche jaate squares badhte hain

    int * res= calloc(n,sizeof(arr));  // sizeof(arr) = pointer (8) → 2x memory, harmless waste
    *returnSize=n;
    int res_index=0;
    while(left_index>=0 && i<n)  // merge step: dono halves mein elements bache hain
    {
        if(abs(arr[left_index])<arr[i])  // chhota square pehle (merge sort jaisa)
        {
            res[res_index++]=arr[left_index]*arr[left_index];
            left_index--;
        }
        else
        {
            res[res_index++]=arr[i]*arr[i];
            i++;
        }
    }
    if(i!=n)  // negatives khatam → right half ke bache squares copy
    {
        while(i<n)
        {
            res[res_index++]=arr[i]*arr[i];
            i++;
        }

    }

    if(left_index>=0)  // non-negatives khatam → left half ke bache squares copy
    {
        while(left_index>=0)
        {
            res[res_index++]=arr[left_index]*arr[left_index];
            left_index--;
        }
    }
    return res;
    
}



/* =========================
    Solution 2 by using 2 pointer --Optimized
   ========================= */

int* sortedSquares(int* arr, int n, int* returnSize) {
    *returnSize=n;
    int* res= calloc (n, sizeof(int));
    int left= 0 , right = n-1, index=n-1;  // index = result ka last slot → bada square peeche se

    while(left<=right)  // <= → left==right wala last element bhi place ho
    {
        if(abs(arr[left])>abs(arr[right]))  // sabse bada square dono ends mein se kisi ek pe
        {
            res[index--]=arr[left]*arr[left];  // left ka square bada → peeche rakho
            left++;
        }
        else
        {
            res[index--]=arr[right]*arr[right];  // right ka square bada (ya equal)
            right--;
        }
    }
    return res;
}
```
