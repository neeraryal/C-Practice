# 283. Move Zeroes
> Saare 0 end mein bhejo, non-zero elements ka relative order same rakho (in-place)

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Two Pointers – read/write with swap](two_pointers.md) | None (2 indices) | O(n) | O(1) |

**How it works**
- **Soch:** [26](<26. Remove Duplicates from Sorted Array.md>) jaisa read/write: `j` padhta hai, `i` agla slot hai jahan next non-zero jaana chahiye. Copy ki jagah **swap** karo — `i` pe pada 0 apne aap `j` pe (peeche) chala jaata hai, end mein zeros alag se fill nahi karne padte.
- **Move:** `arr[j] != 0` → `swap(arr[i], arr[j])`, `i++`. 0 mila → sirf `j++`.
- **Kyun sahi hai:** `arr[0..i-1]` = saare non-zero (left se ek-ek aaye → order same), `arr[i..j-1]` = sirf zeros. Ek pass → O(n).
- **Dry run:** `[0,1,0,3,12]`
  - `j=1`: `1` → swap(0,1) → `[1,0,0,3,12]`, `i=1`
  - `j=3`: `3` → swap(1,3) → `[1,3,0,0,12]`, `i=2`
  - `j=4`: `12` → swap(2,4) → `[1,3,12,0,0]` ✔

**Gotcha:** XOR swap same address pe value 0 kar deta hai (`x ^ x = 0`) — isliye `if(i!=j)` guard zaroori. Bina guard `[1,2,3]` → `[0,0,0]` (shuru mein jab tak 0 nahi milta, `i == j` hi rehta hai).
**vs related:** [26](<26. Remove Duplicates from Sorted Array.md>) copy karta hai (peeche ka data bekaar), yahan zeros bachane hain to swap. [GFG Segregate 0s and 1s](<Segregate 0s and 1s.md>) yahi loop ulti condition (`arr[i]==0`) ke saath → zeros left mein.

<details><summary>Problem statement</summary>

Given an integer array nums, move all 0's to the end of it while maintaining the relative order of the non-zero elements.

Note that you must do this in-place without making a copy of the array.

 

Example 1:

Input: nums = [0,1,0,3,12]
Output: [1,3,12,0,0]
Example 2:

Input: nums = [0]
Output: [0]

</details>

## Code

```c
void swap(int * a, int *b)
{
    *a= *a ^ *b;  // XOR swap (temp ke bina): a = a^b
    *b= *a ^ *b;  // b = (a^b)^b = purana a
    *a= *a ^ *b;  // a = (a^b)^a = purana b
}

void moveZeroes(int* arr, int n) 
{
    int i=0, j=0;  // i = next non-zero ka slot (write), j = reader

    while(j<n)
    {
        if(arr[j]!=0) //if(arr[j]==0) will move all 0 to left 
        {
            if(i!=j)  // same address pe XOR swap → x^x = 0 → value mit jaati
            {swap(&arr[i], &arr[j]);}  // non-zero aage, i pe pada 0 peeche j pe
            i++;  // non-zero region ek badha
        }
        j++;
    }
}
```
