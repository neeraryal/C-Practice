# 75. Sort Colors
> 0/1/2 wale array ko bina library sort ke, one pass mein in-place sort karo (Dutch National Flag)

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Two Pointers – 3-way partition (Dutch flag)](two_pointers.md) | None (3 indices) | O(n) | O(1) |

**How it works**
- **Soch:** Segregate ka 3-value version. Teen pointers array ko 4 hisson mein baant-te hain: `[0, left)` = 0s, `[left, i)` = 1s, `[i, right]` = abhi unknown, `(right, n-1]` = 2s. `i` unknown part ko khatam karta hai.
- **0 mila:** `swap(i, left)`, `left++`, `i++` — `left` pe pehle se 1 tha (ya `i` khud), jo already check ho chuka, to `i` aage badh sakta hai.
- **2 mila:** `swap(i, right)`, `right--`, `i` **wahi** — right se aaya element abhi unknown hai, use dobara check karna padega.
- **1 mila:** sirf `i++`.
- **Kyun sahi hai:** Har step unknown region ek se chhota hota hai (`i++` ya `right--`) → max n steps. Loop `i <= right` kyunki `arr[right]` bhi abhi unknown hai.
- **Dry run:** `[2,0,2,1,1,0]`
  - `i=0` (2): swap with `right=5` → `[0,0,2,1,1,2]`, `right=4`
  - `i=0,1` (0): self-swaps → `left=2`, `i=2`
  - `i=2` (2): swap with `right=4` → `[0,0,1,1,2,2]`, `right=3`
  - `i=2,3` (1): `i=4 > right` → stop ✔

**Gotcha:** Add/sub swap mein `a == b` (same address) ho to `*b = *a - *b = 0` → value mit jaati hai. `i == left` shuru mein hi hota hai, isliye `a!=b` guard zaroori (bina guard `7` → `0`).
**vs related:** [Segregate 0s and 1s](<Segregate 0s and 1s.md>) mein 2 values → ek pointer kaafi. [283](<283. Move all zeros.md>) bhi swap-based partition hai, par order preserve karta hai (yahan zarurat nahi).

<details><summary>Problem statement</summary>

Given an array nums with n objects colored red, white, or blue, sort them in-place so that objects of the same color are adjacent, with the colors in the order red, white, and blue.

We will use the integers 0, 1, and 2 to represent the color red, white, and blue, respectively.

You must solve this problem without using the library's sort function.

 

Example 1:

Input: nums = [2,0,2,1,1,0]
Output: [0,0,1,1,2,2]
Example 2:

Input: nums = [2,0,1]
Output: [0,1,2]

</details>

## Code

```c
void swap (int * a, int *b)
{
    if(a!=b)  // same address → *b = *a - *b = 0 → value mit jaati
    {
        *a = *a + *b;  // add/sub swap (values 0/1/2 → overflow nahi)
        *b = *a - *b;
        *a = *a - *b;
    }
}

void sortColors(int* arr, int n) 
{
    int left=0, right=n-1, i=0;  // [0,left)=0s, [left,i)=1s, [i,right]=unknown, (right,n-1]=2s

    while ( i<= right )  // arr[right] bhi unknown hai → <= zaroori
    {
        if(arr[i]== 0)
        {
            swap(arr+i,arr+left);  // 0 ko 0-region ke end pe bhejo
            left++;  // 0-region badha
            i++;  // left se aaya element 1 hai (ya i khud) → checked, aage badho
        }
        else if (arr[i]==2)
        {
            swap(arr+i,arr+right);  // 2 ko 2-region ke start pe bhejo
            right --;  // i nahi badhta → right se aaya element unknown, dobara check
        }
        else i++;  // 1 → apni jagah pe hai
    }
}
```
