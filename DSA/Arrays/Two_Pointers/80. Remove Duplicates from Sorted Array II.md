# 80. Remove Duplicates from Sorted Array II
> Sorted array mein har value zyada se zyada 2 baar rakho (in-place), naya length `k` return karo

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Two Pointers – read/write, keep at most 2](two_pointers.md) | None (2 indices) | O(n) | O(1) |

**How it works**
- **Soch:** Pehle 2 elements hamesha valid hain. Uske baad `arr[i]` tabhi rakho jab woh kept part ke 2 position peeche wale (`arr[index-2]`) se alag ho — same hai matlab woh value already 2 baar rakh chuke.
- **Read:** `i = 2` se start, har element check.
- **Write:** `arr[i] != arr[index-2]` → `arr[index++] = arr[i]`. Warna skip.
- **Kyun sahi hai:** Kept part `arr[0..index-1]` sorted hai, to `arr[index-2] == arr[i]` matlab `arr[index-1]` bhi same → teesri copy banti. Compare **written** part se hai, original `arr[i-2]` se nahi — woh overwrite ho chuka ho sakta hai (`arr[i-2]` wala version `[1,1,1,2,2,3]` pe `[1,1,2,3]` deta hai).
- **Dry run:** `[1,1,1,2,2,3]`, `index=2`
  - `i=2`: `1 == arr[0]` → skip (teesra 1)
  - `i=3`: `2 != arr[1]=1` → `arr[2]=2`, `index=3`; `i=4`: `2 != arr[1]=1` → `arr[3]=2`, `index=4`
  - `i=5`: `3 != arr[2]=2` → `arr[4]=3` → return `5` → `[1,1,2,2,3,_]` ✔

**Gotcha:** `if(n<=2) return n;` zaroori hai — warna `n=1` pe bhi `index=2` return hota.
**vs related:** [26](<26. Remove Duplicates from Sorted Array.md>) yahi trick "at most 1" ke saath. General "at most k": `index=k` se start, `arr[i] != arr[index-k]`.

<details><summary>Problem statement</summary>

Given an integer array nums sorted in non-decreasing order, remove some duplicates in-place such that each unique element appears at most twice. The relative order of the elements should be kept the same.

Since it is impossible to change the length of the array in some languages, you must instead have the result be placed in the first part of the array nums. More formally, if there are k elements after removing the duplicates, then the first k elements of nums should hold the final result. It does not matter what you leave beyond the first k elements.

Return k after placing the final result in the first k slots of nums.

Do not allocate extra space for another array. You must do this by modifying the input array in-place with O(1) extra memory.

Custom Judge:

The judge will test your solution with the following code:

int[] nums = [...]; // Input array
int[] expectedNums = [...]; // The expected answer with correct length

int k = removeDuplicates(nums); // Calls your implementation

assert k == expectedNums.length;
for (int i = 0; i < k; i++) {
    assert nums[i] == expectedNums[i];
}
If all assertions pass, then your solution will be accepted.

 

Example 1:

Input: nums = [1,1,1,2,2,3]
Output: 5, nums = [1,1,2,2,3,_]
Explanation: Your function should return k = 5, with the first five elements of nums being 1, 1, 2, 2 and 3 respectively.
It does not matter what you leave beyond the returned k (hence they are underscores).
Example 2:

Input: nums = [0,0,1,1,1,1,2,3,3]
Output: 7, nums = [0,0,1,1,2,3,3,_,_]
Explanation: Your function should return k = 7, with the first seven elements of nums being 0, 0, 1, 1, 2, 3 and 3 respectively.
It does not matter what you leave beyond the returned k (hence they are underscores).

## Code

```c
int removeDuplicates(int* arr, int n) 
{
    if(n<=2) return n;  // ≤2 elements → har value max 2 baar, kuch hatana nahi
    int index=2;  // write pointer: pehle 2 elements hamesha valid

    for(int i=2 ;i<n ;i++)  // read pointer
    {
        if(arr[i]!=arr[index-2])  // kept part ke 2 peeche se alag → teesri copy nahi banegi
        {
            arr[index++]=arr[i];  // write + write pointer aage
        }
    }
    return index;  // index = kept elements ka count
}
```
