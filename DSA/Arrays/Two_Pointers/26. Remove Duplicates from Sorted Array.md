# 26. Remove Duplicates from Sorted Array
> Sorted array se duplicates in-place hatao, unique elements ka count `k` return karo

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Two Pointers – read/write (same direction)](two_pointers.md) | None (2 indices) | O(n) | O(1) |

**How it works**
- **Soch:** Array sorted hai → duplicates hamesha paas-paas. Ek pointer (`i`) padhta hai, doosra (`unique_index`) batata hai ki unique part kahan tak bana hai. Naya value mile to unique part ke aage likh do.
- **Read:** `i` har element pe jaata hai, `arr[i]` ko last unique `arr[unique_index]` se compare karo.
- **Write:** Alag mila → `unique_index++` aur wahan `arr[i]` copy. Same mila → skip (duplicate).
- **Kyun sahi hai:** `arr[0..unique_index]` hamesha sorted + unique rehta hai. Sorted hone se naya value sirf last unique se compare karna kaafi hai. Ek pass → O(n).
- **Dry run:** `[1,1,2]`
  - `i=1`: `1 == arr[0]` → skip
  - `i=2`: `2 != 1` → `unique_index=1`, `arr[1]=2`
  - return `1+1 = 2` → `[1,2,_]` ✔

**Gotcha:** `unique_index` last unique ka index hai, count nahi → return `unique_index+1`. `n=0` pe bhi `1` return hoga — constraint `n >= 1` isse bachata hai.
**vs related:** [80](<80. Remove Duplicates from Sorted Array II.md>) mein har value 2 baar tak allowed → `arr[index-2]` se compare. [83](<../../Linked_List/Two_Pointers/83. Remove Duplicates from Sorted List.md>) same idea linked list pe (copy ki jagah `next` skip).

<details><summary>Problem statement</summary>

Given an integer array nums sorted in non-decreasing order, remove the duplicates in-place such that each unique element appears only once. The relative order of the elements should be kept the same.

Consider the number of unique elements in nums to be k​​​​​​​​​​​​​​. After removing duplicates, return the number of unique elements k.

The first k elements of nums should contain the unique numbers in sorted order. The remaining elements beyond index k - 1 can be ignored.

Custom Judge:

The judge will test your solution with the following code:

int[] expectedNums = [...]; // The expected answer with correct length

int k = removeDuplicates(nums); // Calls your implementation

assert k == expectedNums.length;
for (int i = 0; i < k; i++) {
    assert nums[i] == expectedNums[i];
}
If all assertions pass, then your solution will be accepted.

 

Example 1:

Input: nums = [1,1,2]
Output: 2, nums = [1,2,_]
Explanation: Your function should return k = 2, with the first two elements of nums being 1 and 2 respectively.
It does not matter what you leave beyond the returned k (hence they are underscores).
Example 2:

Input: nums = [0,0,1,1,1,2,2,3,3,4]
Output: 5, nums = [0,1,2,3,4,_,_,_,_,_]
Explanation: Your function should return k = 5, with the first five elements of nums being 0, 1, 2, 3, and 4 respectively.
It does not matter what you leave beyond the returned k (hence they are underscores).

## Code

```c
int removeDuplicates(int* arr, int n) 
{
    int unique_index= 0; //element on or before it are unique
    int i=0; // to iterate

    while (i<n)  // read: i=0 pe arr[0]==arr[0] → harmless skip
    {
        if(arr[i]!= arr[unique_index])  // naya value? sorted → sirf last unique se compare kaafi
        {
            unique_index++;  // unique part ek slot aage badhao
            {
                arr[unique_index]=arr[i];  // write: naya value unique part ke end pe
            }
        }
        i++;
    }
    return unique_index+1;  // last unique ka index (0-based) → count = +1
}
```
