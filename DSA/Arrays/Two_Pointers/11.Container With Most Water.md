# 11. Container With Most Water
> Do lines chuno jinke beech (x-axis ke saath) sabse zyada paani aaye — max area return karo

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Two Pointers – opposite ends, move the shorter side](two_pointers.md) | None (2 indices) | O(n) | O(1) |

**How it works**
- **Soch:** Area = `width × min(height)`. Sabse wide container (dono ends) se shuru karo. Andar jaane pe width ghategi, to area tabhi badh sakta hai jab min height badhe.
- **Move:** Area nikal ke `max` update karo. Phir **chhoti** line wala pointer andar le jao (`arr[left] <= arr[right]` → `left++`, warna `right--`).
- **Kyun sahi hai:** Chhoti line bottleneck hai — use kisi bhi andar wali line ke saath lo, width kam aur height ≤ chhoti line → area current se zyada ho hi nahi sakta. To chhoti line safely discard. Har step ek line discard → O(n).
- **Dry run:** `[1,8,6,2,5,4,8,3,7]`
  - `L=0,R=8`: `8 × 1 = 8`, `1 < 7` → `left++`
  - `L=1,R=8`: `7 × 7 = 49`, `8 > 7` → `right--`
  - baaki sab chhote (`6×3=18`, `5×8=40`, ...) → **49** ✔

**Gotcha:** Badi line ko move karna galat hai — width ghategi aur height phir bhi chhoti line tak hi rahegi. `fmin` `double` return karta hai (`<math.h>`) → `int` mein convert; heights chhote integers hain to sahi.
**vs related:** [977](<977. Squares of a Sorted Array.md>) bhi opposite ends, par wahan dono ends merge hote hain; yahan ek end greedy discard. [167](<../Two_Sum/167. Two Sum II - Input Array Is Sorted.md>) mein bhi "ye end ab kisi kaam ka nahi" wala proof.

<details><summary>Problem statement</summary>

You are given an integer array height of length n. There are n vertical lines drawn such that the two endpoints of the ith line are (i, 0) and (i, height[i]).

Find two lines that together with the x-axis form a container, such that the container contains the most water.

Return the maximum amount of water a container can store.

Notice that you may not slant the container.

 

Example 1:

Input: height = [1,8,6,2,5,4,8,3,7]
Output: 49
Explanation: The above vertical lines are represented by array [1,8,6,2,5,4,8,3,7]. In this case, the max area of water (blue section) the container can contain is 49.
Example 2:

Input: height = [1,1]
Output: 1

</details>

## Code

```c
int maxArea(int* arr, int n) {

    int left=0 , right=n-1;  // sabse wide container se shuru

    int max= 0;

    while(left<right)  // container ke liye 2 alag lines chahiye
    {
        int width = right-left;
        int height = fmin(arr[left],arr[right]);  // paani chhoti line tak hi (fmin double → int)
        int volume= width*height;

        max=max>volume?max:volume;  // record answer

        if(arr[left]<=arr[right]) left++;  // left chhoti → bottleneck, discard; andar badi mil sakti
        else right--;  // right chhoti → discard
    }
    return max;
}
```
