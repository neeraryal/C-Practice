# 121. Best Time to Buy and Sell Stock
> Ek din buy, baad ke kisi din sell — max profit do (profit na bane to 0)

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Kadane – running min buy price](kadane.md) | 2 variables (`buy_price`, `profit`) | O(n) | O(1) |

**How it works**
- **Soch:** Har din ko sell day maan lo. Us din ka best buy = ab tak ka sabse sasta din. To bas running minimum `buy_price` aur `arr[i] - buy_price` ka max chahiye. Kadane view: `sell - buy` = beech ke daily differences ka sum → differences pe max subarray.
- **Track min:** `arr[i] < buy_price` → naya sasta din, `buy_price` update aur `continue` (aaj hi buy kiya to aaj sell ka profit ≤ 0).
- **Record answer:** warna `profit = max(profit, arr[i] - buy_price)`.
- **Kyun sahi hai:** Optimal pair mein buy = sell day se pehle ka minimum, aur loop har sell day pe exactly wahi minimum rakhta hai. `profit` 0 se start → sirf girte prices pe answer 0. Ek pass → O(n).
- **Dry run:** `[7,1,5,3,6,4]`
  - `1`: naya min → buy_price=1
  - `5`: profit=4; `3`: 2 < 4 → 4 hi rehta
  - `6`: profit=5; `4`: 3 → `5` ✔

**Gotcha:** `buy_price = arr[0]` → `n ≥ 1` maan ke chalta hai (LeetCode constraint). `>` strict hai — equal price pe min update na karo to bhi profit same aata hai.
**vs related:** [53](<53. Maximum Subarray(Kadanes).md>) ko `arr[i]-arr[i-1]` differences pe chalao to yahi answer. [122](<122. Best Time to Buy and Sell Stock II.md>) mein unlimited transactions → min track nahi, har positive difference jodo.

<details><summary>Problem statement</summary>

You are given an array prices where prices[i] is the price of a given stock on the ith day.

You want to maximize your profit by choosing a single day to buy one stock and choosing a different day in the future to sell that stock.

Return the maximum profit you can achieve from this transaction. If you cannot achieve any profit, return 0.

Example 1:

Input: prices = [7,1,5,3,6,4]
Output: 5
Explanation: Buy on day 2 (price = 1) and sell on day 5 (price = 6), profit = 6-1 = 5.
Note that buying on day 2 and selling on day 1 is not allowed because you must buy before you sell.
Example 2:

Input: prices = [7,6,4,3,1]
Output: 0
Explanation: In this case, no transactions are done and the max profit = 0.

</details>

## Code

```c
int maxProfit(int* arr, int n) 
{
    int profit=0;  // 0 se start → koi profitable din nahi to answer 0
    int buy_price=arr[0];  // ab tak ka sabse sasta din (running min)
    for (int i=1 ;i<n; i++)  // har din ko sell day maan ke check
    {
        if(buy_price > arr[i])  // naya min mila → yahi better buy day
        {
            buy_price=arr[i];
            continue;  // aaj buy kiya → aaj sell ka profit 0, skip
        }
        profit=profit>(arr[i]-buy_price)?profit:(arr[i]-buy_price);  // record answer: aaj sell karein to profit
    }

    return profit;
}
```
