# 53. Maximum Subarray
> Contiguous subarray ka maximum sum return karo

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Kadane – max sum, reset on ≤ 0](kadane.md) | Sirf 2 variables (`sum`, `res`) | O(n) | O(1) |

**How it works**
- **Soch:** Har index pe ek hi decision: purana subarray aage badhao ya yahin se naya shuru karo? Running `sum` ≤ 0 ho gaya to wo aage wale elements ko sirf neeche kheenchega → drop karo, `sum = 0` se naya start.
- **Expand:** `sum += arr[right]` — current element ko running subarray mein jodo.
- **Record answer:** `res = max(res, sum)` — reset se **pehle**, taaki all-negative array mein best single element bhi pakda jaaye.
- **Reset:** `sum <= 0` → `sum = 0`.
- **Kyun sahi hai:** Best subarray ka koi bhi prefix negative nahi ho sakta (warna use hata ke sum aur bada hota) → negative prefix drop karna safe hai. Ek pass → O(n), O(1).
- **Dry run:** `[-2,1,-3,4,-1,2,1,-5,4]`
  - `-2`: sum=-2, res=-2 → reset; `1`: sum=1, res=1
  - `-3`: sum=-2 → reset
  - `4,-1,2,1`: sum 4→3→5→6, res=6
  - `-5,4`: sum 1→5, res 6 hi rehta → `6` ✔

**Gotcha:** `res = arr[0]` se start (0 se nahi) — `[-3,-1,-2]` pe answer `-1` hai, 0 nahi. Isliye record reset se pehle hai. `left` declare hai par use nahi hota (subarray ke indices chahiye hon tab kaam aata).

Given an integer array nums, find the subarray with the largest sum, and return its sum.

 

Example 1:

Input: nums = [-2,1,-3,4,-1,2,1,-5,4]
Output: 6
Explanation: The subarray [4,-1,2,1] has the largest sum 6.
Example 2:

Input: nums = [1]
Output: 1
Explanation: The subarray [1] has the largest sum 1.
Example 3:

Input: nums = [5,4,-1,7,8]
Output: 23
Explanation: The subarray [5,4,-1,7,8] has the largest sum 23.

</details>

## Code

```c
int maxSubArray(int* arr, int n) 
{
    int sum=0,res=arr[0];  // res = arr[0] → all-negative array mein bhi sahi max
    int left =0, right=0;  // left unused — sirf right se scan hota hai

    while(right<n)
    {
        sum+=arr[right];  // expand: arr[right] ko current subarray mein jodo
        res=res>sum?res:sum;  // record answer — reset se pehle, negative sum bhi count ho
        if(sum<=0)  // sum ≤ 0 → ye prefix aage sirf nuksaan karega
        {
            sum=0;  // reset: agle element se naya subarray
        }
        right++;
    }
    return res;    
}
```
