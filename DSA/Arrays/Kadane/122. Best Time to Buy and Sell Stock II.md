# 122. Best Time to Buy and Sell Stock II
> Jitni marzi transactions (ek time pe max 1 share) — max total profit do

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Kadane family – greedy sum of positive differences](kadane.md) | 1 variable (`profit`) | O(n) | O(1) |

**How it works**
- **Soch:** Koi bhi upar jaata stretch `a → b` uske daily steps ka sum hai. Unlimited transactions allowed hain, to har positive `arr[i]-arr[i-1]` le lo aur negative chhod do — ek lamba subarray dhoondhne ki zarurat hi nahi.
- **Add:** `val = arr[i] - arr[i-1]` (kal buy, aaj sell); `val > 0` → `profit += val`.
- **Kyun sahi hai:** Kisi bhi buy-sell ka profit = beech ke differences ka sum ≤ unme se sirf positive differences ka sum. Saare positive lene se ye upper bound achieve ho jaata hai (same din sell + buy allowed). Ek pass → O(n).
- **Dry run:** `[7,1,5,3,6,4]`
  - diffs: `-6, +4, -2, +3, -2`
  - sirf positive jodo: `4 + 3` → `7` ✔

**Gotcha:** `[1,2,3,4,5]` pe `1+1+1+1 = 4` aata hai = ek hi transaction 1→5 — daily steps jodna aur ek lamba trade same hai. `if(n==1) return 0;` zaroori nahi, loop waise bhi nahi chalta.
**vs related:** [121](<121. Best Time to Buy and Sell Stock.md>) mein sirf ek transaction → running min chahiye. Yahan unlimited → greedy, na min na reset.

<details><summary>Problem statement</summary>

You are given an integer array prices where prices[i] is the price of a given stock on the ith day.

On each day, you may decide to buy and/or sell the stock. You can only hold at most one share of the stock at any time. However, you can sell and buy the stock multiple times on the same day, ensuring you never hold more than one share of the stock.

Find and return the maximum profit you can achieve.

 

Example 1:

Input: prices = [7,1,5,3,6,4]
Output: 7
Explanation: Buy on day 2 (price = 1) and sell on day 3 (price = 5), profit = 5-1 = 4.
Then buy on day 4 (price = 3) and sell on day 5 (price = 6), profit = 6-3 = 3.
Total profit is 4 + 3 = 7.
Example 2:

Input: prices = [1,2,3,4,5]
Output: 4
Explanation: Buy on day 1 (price = 1) and sell on day 5 (price = 5), profit = 5-1 = 4.
Total profit is 4.
Example 3:

Input: prices = [7,6,4,3,1]
Output: 0
Explanation: There is no way to make a positive profit, so we never buy the stock to achieve the maximum profit of 0.

</details>

## Code

```c
int maxProfit(int* arr, int n) 
{
    int profit =0;
    if(n==1) return 0;  // ek din → koi transaction nahi (loop bhi skip hota)
    for (int i=1; i<n;i++)
    {
        int val= arr[i]-arr[i-1];  // kal buy, aaj sell ka profit
        profit += val > 0 ? val : 0;  // sirf positive step lo → har upar-jaata stretch cover
    }
    return profit;
}

//buy and sell consecutive days and add profit only if it makes any.
```
