# 169. Majority Element
> `n/2` se zyada baar aane wala element return karo (guaranteed exist karta hai)

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Boyer–Moore Voting](boyer_moore_voting.md) | 2 variables (`majority_element`, `majority_count`) | O(n) | O(1) |

**How it works**
- **Soch:** Do *alag* elements ka pair ek-dusre ko cancel kar do. Majority ke `> n/2` copies hain, to baaki saare mil ke bhi use poora cancel nahi kar sakte — last mein wahi bachta hai.
- **Pick candidate:** `majority_count == 0` → purane saare votes cancel ho chuke, current `arr[i]` naya candidate.
- **Vote:** candidate jaisa → `count++`; alag → `count--` (ek candidate + ek alag element ka pair cancel).
- **Kyun sahi hai:** Har `count--` ek candidate aur ek different element ko saath mein hatata hai. Non-majority elements `< n/2` hain, to wo majority ki saari copies cancel nahi kar sakte → final candidate majority hi hai. Majority guaranteed hai, isliye count verify karne wala doosra pass nahi chahiye. O(n), O(1).
- **Dry run:** `[2,2,1,1,1,2,2]`
  - `2,2` → cand=2, count=2; `1,1` → count=0
  - `1` → cand=1, count=1; `2` → count=0
  - `2` → cand=2, count=1 → `2` ✔

**Gotcha:** Majority guaranteed na ho to bhi ye koi candidate de dega (`[1,2,3]` → `3`) — tab doosre pass mein count `> n/2` verify karna padta. Final `majority_count` asli frequency nahi, sirf bacha hua surplus hai.
**vs related:** [53](<../Kadane/53. Maximum Subarray(Kadanes).md>) jaisa hi one-pass "running state, 0 pe reset" idea — wahan sum, yahan vote count. Hash map count bhi O(n) hai par O(n) space leta hai.

<details><summary>Problem statement</summary>

Given an array nums of size n, return the majority element.

The majority element is the element that appears more than ⌊n / 2⌋ times. You may assume that the majority element always exists in the array.

 

Example 1:

Input: nums = [3,2,3]
Output: 3
Example 2:

Input: nums = [2,2,1,1,1,2,2]
Output: 2
 

Constraints:

n == nums.length
1 <= n <= 5 * 104
-109 <= nums[i] <= 109
The input is generated such that a majority element will exist in the array.

</details>

## Code

```

/*
Problem 169: Majority Element

Intuition kya hai? Isme humein wo element chahiye jo n/2 se zyada baar aaya ho. Ye guarantee hai ki aisa element exist karta hai. Hash map se O(n) space lagta, sort se O(n log n) time, isliye hum voting use karte hain jo O(n) time aur O(1) space mein ho jata hai.

Socho ki ek candidate hai aur ek count hai. Array ko left se right dekhte hain. Agar current element candidate jaisa hai, to candidate ko ek vote mil gaya, count badhao. Agar alag hai, to wo candidate ke ek vote ko cancel kar deta hai, count ghatao. Jab count 0 ho jaye, matlab ab tak ke saare votes aapas mein cancel ho chuke hain, to naya candidate current element ko bana lo.

Ye kaam kyun karta hai? Majority element n/2 se zyada baar aata hai. Har baar jab koi dusra element usko cancel karta hai, to ek majority element aur ek non-majority element dono ek saath hat jaate hain. Non-majority elements total n/2 se kam hain, to wo saare mil ke bhi majority ke saare votes cancel nahi kar sakte. Isliye end mein majority element hi bachega.

Ek cheez dhyaan rakhni hai: ye tabhi sahi hai jab majority element guarantee ho. Agar guarantee na ho (jaise [1,2,3]), to end mein jo candidate bacha wo majority nahi bhi ho sakta. Tab ek aur pass lagake candidate ki count verify karni padti hai.

Example: [2, 2, 1, 1, 1, 2, 2]
- 2: count 0 tha, candidate = 2, count = 1
- 2: same, count = 2
- 1: alag, count = 1
- 1: alag, count = 0
- 1: count 0 tha, candidate = 1, count = 1
- 2: alag, count = 0
- 2: count 0 tha, candidate = 2, count = 1
Answer = 2

O(n) time, O(1) space.
*/

int majorityElement(int* arr, int n)
{
    int candidate = 0;                     // current candidate (pehle step pe overwrite hoga)
    int count = 0;                         // candidate ke bache hue votes

    for (int i = 0; i < n; i++)
    {
        if (count == 0)                    // saare purane votes cancel → naya candidate chuno
        {
            candidate = arr[i];
            count = 1;                     // is element ka apna ek vote
        }
        else if (arr[i] == candidate)      // candidate jaisa hai → vote badhao
        {
            count = count + 1;
        }
        else                               // alag hai → candidate ke ek vote ko cancel karo
        {
            count = count - 1;
        }
    }

    return candidate;                      // majority guaranteed → verify pass nahi chahiye
}
```

```c
int majorityElement(int* arr, int n) 
{
    int majority_count=0;
    int majority_element=0;

    for(int i=0 ;i<n;i++)
    {
        if(majority_count == 0 )  // saare purane votes cancel → naya candidate chuno
        {
            majority_element=arr[i];  // current element ab candidate
        }
        if(majority_element==arr[i])  // candidate ka support → vote badhao
        {
            majority_count++;
        }
        else 
        {
            majority_count--;  // alag element → candidate ke saath pair cancel
        }
    }
    return majority_element;  // majority guaranteed → verify pass ki zarurat nahi
}
```
