# 217. Contains Duplicate
> Array mein koi value kam se kam do baar aayi hai to `true`, sab distinct hain to `false`

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Hashing – seen-before set](hashing.md) | `unordered_set<int>` | O(n) avg | O(n) |

**How it works**
- **Soch:** Brute force mein har pair compare karna O(n²) hai. Duplicate ka matlab bas itna hai: "ye value pehle dekhi hai?" — ye sawal hash set O(1) avg mein answer karta hai.
- **Check:** Har `it` pe pehle `mapp.count(it)` — mila to wahi duplicate hai → turant `return true`.
- **Insert:** Nahi mila to `mapp.insert(it)`, taaki aage koi same value aaye to pakdi jaaye.
- **Kyun sahi hai:** Agar `x` index `i < j` pe do baar hai, to `j` pe pahunchte waqt `x` set mein already hai → miss nahi hota. Ek pass, har op O(1) avg → O(n).
- **Dry run:** `[1,2,3,1]`
  - `1`, `2`, `3` set mein nahi → insert → set `{1,2,3}`
  - `1`: set mein hai → `true` ✔

**Gotcha:** Check pehle, insert baad mein — ulta karoge to pehla element hi khud ko duplicate dikhayega. Naam `mapp` hai par ye set hai (sirf presence chahiye, count nahi).
**vs related:** [128](<128. Longest Consecutive Sequence.md>) mein bhi set hai par sawal "`x-1` / `x+1` present hai?" hota hai. [1. Two Sum](<../Two_Sum/1. Two_Sum_Problem.md>) mein "`x` dekha?" ki jagah "partner `target - x` dekha?" → index bhi chahiye, isliye map.

## Code

```cpp
class Solution {
public:
    bool containsDuplicate(vector<int>& nums) 
    {
        unordered_set<int>mapp;  // ab tak dekhe hue numbers → O(1) avg "pehle dekha?" check
        for(auto it : nums)
        {
            if(mapp.count(it) > 0)  // pehle dekha hai → yahi duplicate hai
            {
                return true;  // early exit: ek duplicate kaafi hai
            }
            mapp.insert(it);  // check ke BAAD insert → element khud se match nahi karta
        }
        return false;  // poora array dekh liya, koi repeat nahi → sab distinct
    }
};
```
