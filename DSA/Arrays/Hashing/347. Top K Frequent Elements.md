# 347. Top K Frequent Elements
> Array ke `k` sabse zyada baar aane wale elements return karo (kisi bhi order mein)

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Hashing – freq map + size-k min-heap](hashing.md) | `unordered_map<int,int>` + `priority_queue` with `greater<>` (min-heap) | O(n log k) | O(n) |

**How it works**
- **Soch:** Pehle har number ki freq gino (hash map). Ab top k chahiye — saare unique elements sort karna O(u log u) hai. Size-k **min**-heap rakho: top pe hamesha "ab tak ke top k mein sabse kamzor" hota hai, use evict karna easy.
- **Count:** `mapp[it]++` → `number → freq`.
- **Filter:** Har `{freq, num}` push karo; `size() > k` hote hi `pop()` → sabse kam freq wala bahar.
- **Collect:** End mein heap mein exactly top k bache → `second` (number) nikaal ke `res` mein.
- **Kyun sahi hai:** Jo pop hua uske upar heap mein k elements usse zyada (ya barabar) freq wale hain → wo top k mein ho hi nahi sakta. u unique, har push/pop O(log k) → O(n + u log k).
- **Dry run:** `[1,1,1,2,2,3], k=2` → map `{1:3, 2:2, 3:1}`
  - push `{3,1}`, `{2,2}` → size 2
  - push `{1,3}` → size 3 > 2 → pop min `{1,3}`
  - heap `{2,2}, {3,1}` → `res = [2,1]` ✔ (order allowed)

**Gotcha:** Naam `maxpq` hai par `greater<>` ise **min-heap** banata hai — aur wahi chahiye (top = sabse kam freq → evict). Output ascending freq mein aata hai (`[2,1]`), problem any order allow karta hai.
**vs related:** [217](<217. Contains Duplicate.md>) / [128](<128. Longest Consecutive Sequence.md>) mein sirf presence (set) chahiye thi; yahan count → map. [451](<../../Strings/Hashing/451. Sort Characters By Frequency.md>) mein freq map + bucket sort se saare chars freq order mein.
**Better approach:** Bucket sort ([451](<../../Strings/Hashing/451. Sort Characters By Frequency.md>) jaisa): `bucket[freq]` mein numbers daalo (freq max n), phir `n` se neeche scan karke pehle k utha lo → O(n) time, heap ka `log k` hat jaata hai.

```
/*
Problem 347: Top K Frequent Elements

Intuition kya hai? Isme humein wo k numbers chahiye jo sabse zyada baar aaye hain. Toh pehle ye pata hona chahiye ki kaun sa number kitni baar aaya. Iske liye map use karte hain: key = number, value = wo number kitni baar aaya.

Ab freq mil gayi, toh top k nikalne hain. Sab ko sort karna O(n log n) hota, par humein sirf k chahiye. Toh hum ek min-heap rakhte hain jiska size max k hoga. Heap mein pair daalte hain (freq, number), freq pehle taaki comparison freq pe ho. Heap ka top hamesha sabse kam freq wala hota hai.

Har number ke liye pair heap mein daalo. Agar heap ka size k se bada ho gaya, toh top (sabse kam freq wala) nikaal do, kyunki wo top k mein aa hi nahi sakta. Is tarah end tak heap mein wahi k pair bachte hain jinki freq sabse zyada hai.

Last mein heap se numbers nikaal ke result mein daal do. Order ascending freq mein aayega, problem mein koi bhi order allowed hai.

Ek cheez dhyaan rakhni hai: map ke unique numbers pe loop chahiye. Yahan nums pe loop chalate hain aur jab ek number ka pair heap mein daal dete hain toh uski freq 0 kar dete hain, taaki dobara na jaye.

Example: nums = [1,1,1,2,2,3], k = 2
- map = {1:3, 2:2, 3:1}
- push (3,1) → heap size 1
- push (2,2) → heap size 2
- push (1,3) → size 3 > k, sabse kam (1,3) nikla → heap = {(2,2), (3,1)}
- result = [2, 1]

O(n log k) time, O(n) space.
*/

vector<int> topKFrequent(vector<int>& nums, int k)
{
    unordered_map<int, int> freq;          // key = number, value = kitni baar aaya

    for (int i = 0; i < nums.size(); i++)
    {
        freq[nums[i]] = freq[nums[i]] + 1; // count badhao
    }

    // min-heap: top = sabse kam freq wala pair (freq, number)
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> minHeap;

    for (int i = 0; i < nums.size(); i++)
    {
        int num = nums[i];

        if (freq[num] == 0)                // is number ko pehle hi process kar chuke
            continue;

        minHeap.push({freq[num], num});    // freq pehle → comparison freq pe
        freq[num] = 0;                     // mark done, dobara push nahi hoga

        if ((int)minHeap.size() > k)       // k se zyada → sabse kam freq wala hatao
            minHeap.pop();
    }

    vector<int> res;

    while (!minHeap.empty())
    {
        res.push_back(minHeap.top().second);  // number nikalo (second = num)
        minHeap.pop();
    }

    return res;
}
```

```cpp
class Solution {
public:
    vector<int> topKFrequent(vector<int>& nums, int k) 
    {
        unordered_map<int, int> mapp;

        for(auto &it : nums)
        {
            mapp[it]++;  // freq count: number → kitni baar aaya
        }    

        priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>>maxpq;  // greater<> → MIN-heap (naam maxpq hai); top = sabse kam freq

        for(auto &[num, freq ] : mapp)
        {
            maxpq.push({freq,num});  // freq pehle → pair freq se compare hota hai
            if(maxpq.size()>k)  // k se zyada → sabse kam freq wala (top) evict karo
            {
                maxpq.pop();
            }
        }
        vector<int>res;

        while(!maxpq.empty())
        {
            res.push_back(maxpq.top().second);  // bache k hi answer; order ascending freq (allowed)
            maxpq.pop();
        }

        return res;

    }
};
```
