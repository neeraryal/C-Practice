# 128. Longest Consecutive Sequence
> Unsorted array mein sabse lambi consecutive run (`x, x+1, x+2, ...`) ki length do — O(n) mein

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Hashing – set + sequence start](hashing.md) | `std::set<int>` (ordered tree) | O(n log n); duplicate starts pe worst O(n² log n) | O(n) |

**How it works**
- **Soch:** Sort karke run ginna O(n log n) hai. Set mein sab daal do, to "`x+1` hai?" O(1)/O(log n) mein pata chalta hai. Bas har element se walk mat karo — sirf **run ke start** se karo, warna har run baar baar gina jaayega.
- **Fill:** Saare `nums` set mein (`emplace`) — duplicates apne aap hat jaate hain.
- **Start check:** `it-1` set mein **nahi** → `it` kisi run ka pehla number hai. `it-1` hai → `it` beech ka element hai, skip.
- **Walk:** Start se `current+1` jab tak set mein hai, `count++` → `res = max(res, count)`.
- **Kyun sahi hai:** Har run ka exactly ek start hota hai (sabse chhota number), to har distinct run ek hi baar walk hota hai (agar start ek baar aaye). `std::set` ka har `count` O(log n) → total O(n log n).
- **Dry run:** `[100,4,200,1,3,2]` → set `{1,2,3,4,100,200}`
  - `100`: `99` nahi → start, `101` nahi → count 1
  - `4`: `3` hai → skip; `200` → count 1
  - `1`: `0` nahi → start → `2,3,4` mile → count 4 → `res=4` ✔

**Gotcha:** `std::set` ordered tree hai → har `count` O(log n), total O(n log n) (problem O(n) maangta hai). Loop `nums` pe hai, set pe nahi → start value ki har duplicate copy poora run dobara walk karti hai: 50k × `1` + `2..50000` (n≈1e5) pe 93.7 s laga (O(n²) behaviour), set pe iterate karne wala version 0.002 s.
**vs related:** [217](<217. Contains Duplicate.md>) mein set sirf "`x` pehle dekha?" ke liye tha; yahan neighbour lookup (`x-1`, `x+1`) hai. [347](<347. Top K Frequent Elements.md>) mein presence nahi, count chahiye → map.
**Better approach:** `unordered_set` lo aur second loop **set pe** chalao (`for (int x : s)`) → har distinct start ek hi baar walk hota hai, har element max 2 baar touch → O(n) average.

```
/*
Problem 128: Longest Consecutive Sequence

Intuition kya hai? Isme humein sabse lambi consecutive sequence ki length chahiye (jaise 1,2,3,4), aur O(n) mein chahiye. Sort karenge to O(n log n) ho jayega, isliye set use karte hain.

Pehle saare numbers ek unordered_set mein daal dete hain. Isse "kya x array mein hai?" ka jawab O(1) mein mil jata hai, aur duplicates apne aap hat jaate hain.

Ab socho ki har number se sequence shuru karke aage badhte jayein (x, x+1, x+2...). Ye galat hoga kyunki beech ke number se bhi hum wahi sequence dobara chala denge, aur O(n^2) ho jayega.
To hum sirf wahi number se shuru karte hain jo kisi sequence ka starting point ho. Starting point wo hai jiska pichla number (x-1) set mein nahi hai. Agar x-1 set mein hai, to x beech ka element hai, usko skip kar do.

Starting point mil gaya to uske aage x+1, x+2, ... set mein dekhte jao jab tak mil rahe hain, aur length count karte jao. Har sequence ki length ko answer se compare karke maximum rakho.

Ek cheez dhyaan rakhni hai: nums pe seedha loop chalayein to duplicate starting point ki har copy poori sequence dobara chalegi. Isliye pehle unique numbers ki alag list (uniq) bana lete hain, aur loop usi pe chalate hain.

Har number max ek baar sequence ke andar walk hota hai (sirf start se), isliye total O(n).

Example: nums = [100, 4, 200, 1, 3, 2]
- set = {100, 4, 200, 1, 3, 2}
- 100: 99 nahi hai, start. 101 nahi hai, length 1.
- 4: 3 hai, skip.
- 200: 199 nahi hai, start. 201 nahi hai, length 1.
- 1: 0 nahi hai, start. 2, 3, 4 hain, 5 nahi. length 4.
- 3: 2 hai, skip. 2: 1 hai, skip.
- Answer = 4 ([1, 2, 3, 4])

O(n) average time, O(n) space.
*/

int longestConsecutive(vector<int>& nums)
{
    unordered_set<int> s;                  // fast lookup: x present hai ya nahi
    vector<int> uniq;                      // sirf unique numbers (duplicates ka repeat walk rokne ke liye)

    for (int i = 0; i < nums.size(); i++)
    {
        if (s.count(nums[i]) == 0)         // pehli baar dikha
        {
            s.insert(nums[i]);             // set mein daalo
            uniq.push_back(nums[i]);       // unique list mein daalo
        }
    }

    int res = 0;                           // ab tak ki sabse lambi sequence

    for (int i = 0; i < uniq.size(); i++)
    {
        int x = uniq[i];

        if (s.count(x - 1) == 0)           // x-1 nahi hai → x sequence ka start hai
        {
            int cur = x;                   // sequence ka current number
            int len = 1;                   // x khud ek element hai

            while (s.count(cur + 1) > 0)   // agla number set mein hai → sequence aage badhao
            {
                cur = cur + 1;
                len = len + 1;
            }

            if (len > res)
                res = len;                 // best update
        }
        // x-1 hai → x beech ka element, skip
    }

    return res;                            // empty array pe 0 hi rahega, alag check nahi chahiye
}
```

```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) 
    {
        int size=nums.size();
        if(size==0) return 0;  // empty array → koi sequence nahi
        set<int>s;  // ordered set (tree) → lookup O(log n); unordered_set se O(1) avg
        for(auto it :nums)
        {
            s.emplace(it);  // sab numbers set mein → fast "x present hai?", dups hat jaate
        }
        int res=0;
        for(auto it : nums)  // nums pe loop → duplicate start ki har copy run dobara walk karegi
        {
            if(!s.count(it-1))  // it-1 nahi hai → it run ka start; warna beech ka element, skip
            {
                int count=1 ,current=it;  // start khud run ka pehla element → count 1 se
                while(s.count(current+1))  // next number set mein hai → run aage badhao
                  {
                      count+=1;
                      current+=1;
                  }
                  res=max(res,count);  // record answer: is run ki length
             }
      }          
       return res;
    }
};
```
