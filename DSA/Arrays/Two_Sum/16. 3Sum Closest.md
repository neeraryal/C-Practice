# 16. 3Sum Closest
> Teen numbers ka wo sum return karo jo `target` ke sabse paas ho

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Two Sum – sort + fix one + two pointers](two_sum.md) | None | O(n²) | O(1) |

**How it works**
- **Soch:** 3Sum jaisa hi — sort, `i` fix, baaki pe two pointers. Farak: exact sum nahi, sabse paas wala sum chahiye. Isliye har sum ek candidate hai, aur `abs(target - sum)` ka minimum track karna hai.
- **Move:** `sum < target` → sum badhana hai → `left++`. `sum > target` → `right--`. `sum == target` → isse paas kuch nahi ho sakta → turant return.
- **Track:** Har step `temp_diff = abs(target - sum)`; chhota mila to `res_sum = sum`.
- **Kyun sahi hai:** Pointer moves wahi 167 wala logic hai — jo element hataya wo aage kisi combination mein target ke aur paas nahi la sakta. O(n²).
- **Dry run:** `[-1,2,1,-4], target=1` → sorted `[-4,-1,1,2]`
  - `i=-4`: `-3` (diff 4), `-1` (diff 2)
  - `i=-1`: `-1+1+2 = 2` (diff **1**) → answer `2` ✔

**Gotcha:** `res_sum` sort se pehle `arr[0]+arr[1]+arr[2]` se init hai — harmless, kyunki `diff=INT_MAX` hai to pehli iteration hi overwrite kar deti hai. Diff check pointer move ke baad hai, phir bhi sahi hai kyunki `sum` local mein saved hai.
**vs related:** [15](<15. 3Sum.md>) mein exact match + unique triplets. [GFG Triplets](<Triplets with Smaller Sum.md>) mein count chahiye.

<details><summary>Problem statement</summary>

Given an integer array nums of length n and an integer target, find three integers at distinct indices in nums such that the sum is closest to target.

Return the sum of the three integers.

You may assume that each input would have exactly one solution.

 

Example 1:

Input: nums = [-1,2,1,-4], target = 1
Output: 2
Explanation: The sum that is closest to the target is 2. (-1 + 2 + 1 = 2).
Example 2:

Input: nums = [0,0,0], target = 1
Output: 0
Explanation: The sum that is closest to the target is 0. (0 + 0 + 0 = 0).

</details>

## Code

```c
int cmp_int(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;

    if (x < y) return -1;
    if (x > y) return 1;
    return 0;
}
int threeSumClosest(int* arr, int n, int target) 
{
    int diff=INT_MAX;  // ab tak ka best distance; INT_MAX → pehla sum hi best ban jaata hai
    int res_sum=arr[0]+arr[1]+arr[2];  // sirf placeholder (sort se pehle) — pehli iteration overwrite karegi
    qsort(arr,n,sizeof(int),cmp_int);  // sort → two pointers possible
    for(int i=0;i<n-2;i++)
    {
        int left=i+1;  // arr[i] fix, baaki [i+1..n-1] pe two pointers
        int right=n-1;

        while(left<right)
        {
            int sum=arr[i]+arr[left]+arr[right];
            if(sum==target)
                return target;  // exact mila → isse paas kuch nahi ho sakta
            else if(sum<target)
                left++;  // sum chhota → badhane ke liye left aage
            else
                right--;  // sum bada → ghatane ke liye right peeche
            int temp_diff=abs(target-sum);  // ye sum bhi candidate hai — target se kitna door?
            if(temp_diff<diff)
            {
                diff=temp_diff;
                res_sum=sum;  // naya closest sum
            }
        }
    }
    return res_sum;
}
```
