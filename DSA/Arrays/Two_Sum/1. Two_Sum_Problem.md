# 1. Two Sum
> Unsorted array mein do elements ke indices return karo jinka sum `target` ho (exactly ek answer hai)

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Two Sum – hash complement](two_sum.md) | Custom hash map (chaining, `MAP_SIZE` 20011) | O(n) avg | O(n) |

**How it works**
- **Soch:** Har `arr[i]` ka partner fixed hai: `target - arr[i]`. Brute force mein har pair check karna O(n²) hai. Agar pehle dekhe hue numbers hash map mein `value → index` rakhe hon, to partner O(1) mein mil jaata hai.
- **Search first:** Har `i` pe pehle `search(target - arr[i])` karo. Mila to `res = {partner ka index, i}`.
- **Phir insert:** Nahi mila to `insert(arr[i], i)`, taaki aage wale elements isse partner bana sakein.
- **Kyun sahi hai:** Answer pair `(j, i)` with `j < i` — jab loop `i` pe pahunchta hai tab `arr[j]` map mein already hai, isliye pair miss nahi hota. Search insert se pehle hai, isliye element khud ke saath pair nahi banta.
- **Dry run:** `[2,7,11,15], target=9`
  - `i=0`: `9-2=7` map mein nahi → insert `2→0`
  - `i=1`: `9-7=2` mil gaya (index 0) → `[0,1]` ✔

**Gotcha:** `[3,3], target=6` search-before-insert ki wajah se hi chalta hai. Negative keys ke liye hash `(key % MAP_SIZE + MAP_SIZE) % MAP_SIZE` hai, warna index negative ho jaata. Map ke nodes kabhi `free` nahi hote (LeetCode pe chalta hai, real code mein leak).
**vs related:** [167](<167. Two Sum II - Input Array Is Sorted.md>) mein array sorted hai → hash nahi chahiye, two pointers se O(1) space. [560](<../Prefix_Sum/560.Subarray Sum Equals K.md>) mein yahi complement trick prefix sums pe lagti hai (`sum - k`).
**⚠ Known bug:** `insert` mein `new_node->next= current;` — loop ke baad `current` NULL hai, to same bucket mein pehle se pade keys gum ho jaate hain. `[1, 20012, 5], target=6` pe `[0,2]` ki jagah kuch nahi milta. Fix: `new_node->next = MAP[key_index];` (jaise 560 mein hai).

<details><summary>Problem statement</summary>

Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

Example 1:

Input: nums = [2,7,11,15], target = 9
Output: [0,1]
Explanation: Because nums[0] + nums[1] == 9, we return [0, 1].
Example 2:

Input: nums = [3,2,4], target = 6
Output: [1,2]
Example 3:

Input: nums = [3,3], target = 6
Output: [0,1]

</details>

## Code

```c
# define MAP_SIZE 20011 // prime size → keys buckets mein achhe se spread hote hain

/* =========================
   Bucket structure (Chaining used for Collision)
   ========================= */
typedef struct Node{
    int key;
    int value;
    struct Node* next;
}Node;  

/* =========================
   Hash table (array of buckets)
   ========================= */
Node * MAP[MAP_SIZE];

/* =========================
   Initialize hash table
   ========================= */
void initTable(void) {
    for (int i = 0; i < MAP_SIZE; i++) {
        MAP[i] = NULL;
    }
}
/* =========================
   GET HASH/INDEX whee to put key 
   ========================= */
int get_hash(int key )
{
    return (key % MAP_SIZE + MAP_SIZE)% MAP_SIZE; // C mein -ve % -ve deta hai → +MAP_SIZE se index hamesha 0..MAP_SIZE-1
}

/* =========================
   Inset in MAP
   ========================= */
void insert(int key, int value)
{
    int key_index = get_hash(key);
    
    Node* current= MAP[key_index];
    
    //Check if key already exist, if yes then update 
    while(current !=NULL)
    {
        if(current -> key == key )
        {
            //usecase will define what to do for same key, here we are updating.
            current->value = value;
            return;
        }
        current = current->next ;
    }
    
    // There was no key present, so we insert anew one in head.
    Node * new_node = malloc(sizeof(Node));
    new_node->value = value;
    new_node->key = key;
    new_node->next= current;      // ⚠ loop ke baad current NULL hai → bucket ki purani chain gum ho jaati hai; MAP[key_index] hona chahiye
    MAP[key_index]=new_node;      // naya node bucket ka head
    
    return ;
}

/* =========================
   Search in MAP and return
   ========================= */

int* search(int key )
{
    int key_index = get_hash(key);
    
    Node * current = MAP[key_index];
    
    while(current != NULL)
    {
        if(current->key == key)
        {
            return &current->value; // pointer return → NULL se "nahi mila" alag pata chalta hai
        }
        current = current->next;
    }
    return NULL;
}

int* twoSum(int* arr, int n, int target, int* returnSize) 
{
    initTable();                  // har call pe map reset (purane nodes free nahi hote)
    int res_size =2;
    *returnSize = res_size;
    int * res= malloc(sizeof(int) * res_size);

    for(int i=0 ; i< n ;i ++)
    {
        int other_pair = target - arr[i];           // arr[i] ka partner
        int *other_pair_index = search(other_pair); // partner pehle dekha hai kya? (map: value → index)
        if(other_pair_index != NULL)
        {
            res[0]=*other_pair_index;   // partner pehle aaya tha
            res[1]=i;                   // current element baad mein
        }
        else 
        {
            insert(arr[i],i);           // search ke BAAD insert → element khud se pair nahi banata
        }
    }
return res;
    
}
```
