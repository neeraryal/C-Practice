# 15. 3Sum
> Saare unique triplets do jinka sum 0 ho

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Two Sum – sort + fix one + two pointers](two_sum.md) | `int**` result, `realloc` se grow | O(n²) | O(1) extra (output alag) |

**How it works**
- **Soch:** `a + b + c = 0` mein ek element `arr[i]` fix kar do, to baaki problem [167](<167. Two Sum II - Input Array Is Sorted.md>) ban jaati hai: `b + c = -arr[i]`. Sort karne se two pointers bhi milte hain aur duplicates bhi side-by-side aa jaate hain.
- **Fix `i`:** `qsort`, phir har `i` ke liye `left=i+1`, `right=n-1`, `target=-arr[i]`. `arr[i] > 0` hote hi loop band — aage sab positive hain, sum 0 ho hi nahi sakta.
- **Match:** Triplet save karo (capacity full ho to `realloc` se double), phir `left++`, `right--` aur same values skip karo.
- **Kyun sahi hai:** Same `arr[i]` dobara aaye to `continue` (warna same triplets dobara bante). Match ke baad same `arr[left]`/`arr[right]` skip, to same pair dobara nahi aata. n baar O(n) two-pointer → O(n²).
- **Dry run:** `[-1,0,1,2,-1,-4]` → sorted `[-4,-1,-1,0,1,2]`
  - `i=-4`: koi pair 4 nahi banata
  - `i=-1`: `(-1,2)` ✔, `(0,1)` ✔
  - `i=-1` (dup) skip → `[[-1,-1,2],[-1,0,1]]`

**Gotcha:** Duplicate skip teen jagah: `i` pe (`i > 0 &&` zaroori, warna `arr[-1]`), aur match ke baad `left`/`right` pe. `n < 3` pe `i < n-2` loop chalta hi nahi.
**vs related:** [167](<167. Two Sum II - Input Array Is Sorted.md>) + fixed `i`. [16](<16. 3Sum Closest.md>) mein exact 0 ki jagah closest chahiye → duplicate skip nahi, bas min diff track.

<details><summary>Problem statement</summary>

Given an integer array nums, return all the triplets [nums[i], nums[j], nums[k]] such that i != j, i != k, and j != k, and nums[i] + nums[j] + nums[k] == 0.

Notice that the solution set must not contain duplicate triplets.

 

Example 1:

Input: nums = [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
Explanation: 
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0.
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0.
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0.
The distinct triplets are [-1,0,1] and [-1,-1,2].
Notice that the order of the output and the order of the triplets does not matter.
Example 2:

Input: nums = [0,1,1]
Output: []
Explanation: The only possible triplet does not sum up to 0.
Example 3:

Input: nums = [0,0,0]
Output: [[0,0,0]]
Explanation: The only possible triplet sums up to 0.

</details>

## Code

```c
/**
 * Return an array of arrays of size *returnSize.
 * The sizes of the arrays are returned as *returnColumnSizes array.
 * Note: Both returned array and *columnSizes array must be malloced, assume caller calls free().
 */
int cmp_int(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;

    if (x < y) return -1;
    if (x > y) return 1;
    return 0;
}

int** threeSum(int* arr, int n, int* returnSize, int** returnColumnSizes)
{
    qsort(arr, n, sizeof(int), cmp_int);  // sort → two pointers chal sakte hain + duplicates paas-paas aa jaate hain

    int capacity = 1000;  // kitne triplets honge pata nahi → dynamic array, full hone pe double
    int** res = malloc(sizeof(int*) * capacity);
    int* col_arr = malloc(sizeof(int) * capacity);  // har triplet ka size (hamesha 3) — LeetCode ko chahiye

    int res_index = 0;

    for (int i = 0; i < n - 2 && arr[i] <= 0; i++)  // arr[i] > 0 → aage sab positive → sum 0 impossible → stop
    {
        if (i > 0 && arr[i] == arr[i - 1]) continue;  // same fixed value dobara → same triplets banenge → skip

        int left = i + 1;
        int right = n - 1;
        int target = -arr[i];  // ab ye 167 hai: arr[left] + arr[right] == -arr[i]

        while (left < right)
        {
            int sum = arr[left] + arr[right];

            if (sum == target)
            {
                if (res_index == capacity)  // result array full → capacity double karo
                {
                    capacity *= 2;
                    res = realloc(res, sizeof(int*) * capacity);
                    col_arr = realloc(col_arr, sizeof(int) * capacity);
                }

                int* triplet = malloc(sizeof(int) * 3);
                triplet[0] = arr[i];
                triplet[1] = arr[left];
                triplet[2] = arr[right];

                res[res_index] = triplet;
                col_arr[res_index] = 3;
                res_index++;

                left++;  // match mil gaya → dono values use ho gayi, dono pointers aage
                right--;

                while (left < right && arr[left] == arr[left - 1]) left++;  // same left value skip → duplicate triplet nahi
                while (left < right && arr[right] == arr[right + 1]) right--;  // same right value skip
            }
            else if (sum < target)
                left++;  // sum kam → left aage (bada value)
            else
                right--;  // sum zyada → right peeche (chhota value)
        }
    }

    *returnSize = res_index;
    *returnColumnSizes = col_arr;
    return res;
}
```

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n=10;
    int capacity=5;
    int *arr= malloc(sizeof(int)*capacity);
    for(int i=0 ;i<n;i++)
    {
        if(i>=capacity)
        {
            capacity*=2;
            int*temp=NULL;
            temp=realloc(arr, sizeof(int)*capacity); //Why temp ? we can assign arr directly , but what if there is no memory , then   it will fail and we'll loose arr as well.
            if(temp ==NULL)
            {
                free(arr);
                return 1;
            }
            arr=temp;
        }
        arr[i]=i;
    }
    
    for (int i=0 ;i<n ;i++)
    {
        printf("%3d",*(arr+i));
    }
    return 0;
}
```
