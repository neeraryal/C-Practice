# 66. Plus One
> Digits array mein store bade number mein 1 jodo, result ke digits return karo

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Simulation – right-to-left carry](simulation.md) | `n+1` size `malloc` result | O(n) | O(n) |

**How it works**
- **Soch:** Bilkul haath wala addition: last digit pe `+1`, carry left mein propagate. Result ek digit lamba ho sakta hai (`999 → 1000`), isliye pehle se `n+1` jagah le lo.
- **Carry propagate:** `carry = 1` se start (yahi "+1" hai). Right se left: `sum = arr[i] + carry`, `res[i+1] = sum % 10`, `carry = sum / 10`. `res` ek position shifted hai — `res[0]` final carry ke liye reserved.
- **Final carry:** bacha → `res[0] = 1`, size `n+1`. Nahi bacha → `res+1` return, size `n`.
- **Kyun sahi hai:** Grade-school addition step by step; carry sirf tab aage jaata hai jab digit 9 thi. Ek pass → O(n).
- **Dry run:** `[1,2,3]`
  - `i=2`: 3+1=4 → res[3]=4, carry=0
  - `i=1,0`: res[2]=2, res[1]=1
  - carry 0 → `res+1` = `[1,2,4]` ✔ (par ⚠ dekho)

**Gotcha:** Extra digit sirf tab jab saare digits 9 hon (`[9,9] → [1,0,0]`) — `n+1` pehle se allocate karne se `realloc` nahi karna padta, par common case mein ek slot waste hota hai.
**vs related:** [15. 3Sum](<../Two_Sum/15. 3Sum.md>) bhi LeetCode ka "malloc karke return, caller free karega" convention follow karta hai — wahan size pata nahi to `realloc` se grow.
**⚠ Known bug:** Carry na bache to `return res+1;` — `malloc` block ke **beech** ka pointer. Caller (problem kehti hai "caller calls free()") us pe `free()` kare to undefined behaviour: `[1,2,3]` ka result free karte hi `free(): invalid pointer` → abort. Fix: `memmove(res, res+1, n*sizeof(int))` karke `res` hi return karo (ya pehle `n` size lo, carry aaye tabhi grow karo).

<details><summary>Problem statement</summary>

You are given a large integer represented as an integer array digits, where each digits[i] is the ith digit of the integer. The digits are ordered from most significant to least significant in left-to-right order. The large integer does not contain any leading 0's.

Increment the large integer by one and return the resulting array of digits.

Example 1:

Input: digits = [1,2,3]
Output: [1,2,4]
Explanation: The array represents the integer 123.
Incrementing by one gives 123 + 1 = 124.
Thus, the result should be [1,2,4].
Example 2:

Input: digits = [4,3,2,1]
Output: [4,3,2,2]
Explanation: The array represents the integer 4321.
Incrementing by one gives 4321 + 1 = 4322.
Thus, the result should be [4,3,2,2].
Example 3:

Input: digits = [9]
Output: [1,0]
Explanation: The array represents the integer 9.
Incrementing by one gives 9 + 1 = 10.
Thus, the result should be [1,0].

</details>

## Code

```c
/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
int* plusOne(int* arr, int n, int* returnSize) {
    int carry =1 ;  // carry = 1 se start → yahi "+1" hai
    int * res = malloc(sizeof(int) * (n+1));  // n+1 → 999 jaise case mein extra digit ki jagah

    for(int i= n-1; i>=0 ;i--)  // LSD (right) se left, jaise haath se jodte hain
    {
        int sum = arr[i]+carry;
        res[i+1]=sum%10;  // res ek shift aage → res[0] final carry ke liye khaali
        carry=sum/10;  // sum 10 hua to carry 1 aage jaayega
    }

    if(carry)  // saare digits 9 the → number ek digit lamba
    {
        res[0]=1;  // final carry sabse aage
        *returnSize=n+1;
        return res;
    }
    else 
    {
        *returnSize=n;
        return res+1;  // ⚠ malloc block ke beech ka pointer → caller ka free() UB
    }

}
```
