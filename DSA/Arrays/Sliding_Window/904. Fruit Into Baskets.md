# 904. Fruit Into Baskets
> Sabse lamba subarray jisme zyada se zyada 2 alag fruit types hon

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Variable sliding window – at most K distinct](sliding_window.md) | `bucket` freq array (`calloc(n)`) + `unique_count` | O(n) | O(n) |

**How it works**
- **Soch:** 2 baskets = window mein `<= 2` distinct types. Story hatao to ye "longest subarray with at most 2 distinct values" hai. Distinct count ke liye freq array + counter ([2461](<2461. Maximum Sum of Distinct Subarrays With Length K.md>) wali trick), window variable ([1004](<1004. Max Consecutive Ones III.md>) jaisi).
- **Expand:** `bucket[arr[right]]++`; count 1 hua → naya type → `unique_count++`.
- **Shrink:** `while (unique_count > 2)` → `bucket[arr[left]]--`, 0 hua to `unique_count--`, `left++`.
- **Record:** Shrink ke baad window valid → `res = max(res, right-left+1)`.
- **Kyun sahi hai:** Badi window mein types zyada ya barabar hi honge (monotonic). Har `right` ke liye sabse chhota valid `left`, aur `left` sirf aage → O(n).
- **Dry run:** `[1,2,3,2,2]` (Example 3)
  - `right=1`: `{1,2}` → len 2
  - `right=2`: 3 aaya → 3 types → 1 nikla, `left=1` → `[2,3]`
  - `right=4`: `[2,3,2,2]` → len **4** ✔

**Gotcha:** `bucket` ka size `n` hai aur index `arr[i]` se hota hai — ye sirf LeetCode ke `0 <= fruits[i] < fruits.length` constraint ki wajah se safe hai. `free(bucket)` return se pehle hai, to leak nahi.
**vs related:** [1004](<1004. Max Consecutive Ones III.md>) mein condition zeros `<= k`, yahan types `<= 2`. Strings mein [GFG K Uniques](<../../Strings/Sliding_Window/Longest Substring with K Uniques.md>) yahi "≤K distinct" idea hai (wahan exactly `k` distinct pe record).

<details><summary>Problem statement</summary>

Fruit Into Baskets

You are visiting a farm that has a single row of fruit trees arranged from left to right. The trees are represented by an integer array fruits where fruits[i] is the type of fruit the ith tree produces.

You want to collect as much fruit as possible. However, the owner has some strict rules that you must follow:

You only have two baskets, and each basket can only hold a single type of fruit. There is no limit on the amount of fruit each basket can hold.
Starting from any tree of your choice, you must pick exactly one fruit from every tree (including the start tree) while moving to the right. The picked fruits must fit in one of your baskets.
Once you reach a tree with fruit that cannot fit in your baskets, you must stop.
Given the integer array fruits, return the maximum number of fruits you can pick.


Example 1:

Input: fruits = [1,2,1]
Output: 3
Explanation: We can pick from all 3 trees.
Example 2:

Input: fruits = [0,1,2,2]
Output: 3
Explanation: We can pick from trees [1,2,2].
If we had started at the first tree, we would only pick from trees [0,1].
Example 3:

Input: fruits = [1,2,3,2,2]
Output: 4
Explanation: We can pick from trees [2,3,2,2].
If we had started at the first tree, we would only pick from trees [1,2].

</details>

## Code

```c
int totalFruit(int* arr, int n) 
{
    int left=0, right=0;
    int unique_count=0;  // window mein kitne fruit types (valid jab <= 2)
    int res=0;
    
    int *bucket = calloc(n,sizeof(int));  // type → count; size n kyunki fruits[i] < n (constraint)
    while(right<n)
    {

        bucket[arr[right]]+=1;  // expand: fruit window mein
        if(bucket[arr[right]]==1)unique_count+=1;  // naya type aaya → distinct recalculate

        while(unique_count>2)  // 3rd type → window invalid → left se shrink
        {
            bucket[arr[left]]-=1;  // shrink: arr[left] window se bahar
            if(bucket[arr[left]]==0)  // type window se poora gaya → count ghatao
                unique_count--;
            left++;
        }
        res=res>(right-left+1)?res:(right-left+1);  // window valid → record answer (maximize)
        right++;
    }
    free(bucket);
    return res;
}
```
