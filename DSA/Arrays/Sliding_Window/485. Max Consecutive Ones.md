# 485. Max Consecutive Ones
> Binary array mein lagatar 1s ka sabse lamba run

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Run counting (sliding window ka precursor)](sliding_window.md) | ek index + `one_count` | O(n) | O(1) |

**How it works**
- **Soch:** Variable `right` hai par `left` nahi — ye asli sliding window nahi, plain scan hai. Current 1s ka run gino, 0 aate hi run khatam. 0 pe reset = poori window drop; jab kuch 0s allow hon ([1004](<1004. Max Consecutive Ones III.md>)) tab reset nahi chalega, `left` pointer chahiye.
- **Track:** `arr[right]==1` → `one_count++` aur turant `res` update.
- **Reset:** `arr[right]==0` → `one_count = 0`.
- **Kyun sahi hai:** Har run ke andar har step pe `res` update hota hai, to sabse lamba run miss nahi hota. Ek pass → O(n).
- **Dry run:** `[1,1,0,1,1,1]`
  - `1,1` → count 2, `res=2`
  - `0` → count 0
  - `1,1,1` → count 3, `res=`**3** ✔

**Gotcha:** `res` update loop ke andar (har 1 pe) hai, isliye array ke end tak chalne wala run bhi count hota hai — loop ke baad alag check nahi chahiye. Saare 0 → `res` 0 hi rehta hai.
**vs related:** [1004](<1004. Max Consecutive Ones III.md>) isi ka upgrade hai: `k` zeros flip allowed → reset ki jagah left se shrink, yahi asli variable sliding window hai (`k=0` pe dono same).

<details><summary>Problem statement</summary>

Given a binary array nums, return the maximum number of consecutive 1's in the array.

 

Example 1:

Input: nums = [1,1,0,1,1,1]
Output: 3
Explanation: The first two digits or the last three digits are consecutive 1s. The maximum number of consecutive 1s is 3.
Example 2:

Input: nums = [1,0,1,1,0,1]
Output: 2

</details>

## Code

```c
int findMaxConsecutiveOnes(int* arr, int n) 
{
    int right=0;  // sirf ek pointer, left nahi → plain scan (1004 ka precursor)
    int one_count=0;  // current 1s ka run length
    int res=0;
    while(right<n)
    {
        if(arr[right]==1)
        {
            one_count++;  // run aage badha
            res=res>one_count?res:one_count;  // har 1 pe record → end tak chalne wala run bhi count
        }
        else
        {
            one_count=0;  // 0 aaya → run khatam, reset (1004 mein yahan shrink hota hai)
        }
        right++;
    }
    return res;
}
```
