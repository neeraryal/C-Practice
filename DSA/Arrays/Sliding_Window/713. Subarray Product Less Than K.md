# 713. Subarray Product Less Than K
> Kitne contiguous subarrays ka product strictly `< k` hai — count karo

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Variable sliding window – count](sliding_window.md) | 2 indices + running product (`long long`) | O(n) | O(1) |

**How it works**
- **Soch:** Saare numbers `>= 1` hain → window badhao to product badhta hai, chhota karo to ghatta hai (monotonic) → sliding window. Har `right` ke liye sabse lambi valid window dhoondho, phir ek saath count karo.
- **Guard:** `if (k <= 1) return 0;` — product hamesha `>= 1` hai, to `< k` kabhi nahi hoga. Guard ke bina window khaali hone pe bhi (`prod = 1`) `prod >= k` sach rehta hai → `left` `right` se aage nikal jaata hai (`k=1, [1,2]` → -1 aata hai).
- **Expand / Shrink:** `prod *= arr[right]`; jab tak `prod >= k` → `prod /= arr[left]`, `left++`.
- **Count:** `[left..right]` valid hai to `right` pe khatam hone wala har subarray `[i..right]` (`i >= left`) bhi valid hai (chhota product) → `right-left+1` naye subarrays. Har subarray apne right end pe exactly ek baar gina jaata hai.
- **Kyun sahi hai:** `left` sirf aage jaata hai, har element ek baar multiply, ek baar divide → O(n).
- **Dry run:** `[10,5,2,6], k=100`
  - `right=0`: `[10]` → +1; `right=1`: `[10,5]`=50 → +2
  - `right=2`: 100 >= k → 10 nikla → `[5,2]` → +2
  - `right=3`: `[5,2,6]`=60 → +3 → total **8** ✔

**Gotcha:** `prod /= arr[left]` exact division hai kyunki `arr[left]` pehle multiply hua tha. `prod` `long long` hai — shrink ke baad `prod < k`, phir agla multiply `k * max(nums)` tak ja sakta hai.
**vs related:** [209](<209. Minimum Size Subarray Sum.md>) mein shortest window chahiye (record shrink loop ke andar); yahan count chahiye → har `right` pe `right-left+1` add. [1004](<1004. Max Consecutive Ones III.md>) window maximize karta hai.

<details><summary>Problem statement</summary>

Given an array of integers nums and an integer k, return the number of contiguous subarrays where the product of all the elements in the subarray is strictly less than k.

 

Example 1:

Input: nums = [10,5,2,6], k = 100
Output: 8
Explanation: The 8 subarrays that have product less than 100 are:
[10], [5], [2], [6], [10, 5], [5, 2], [2, 6], [5, 2, 6]
Note that [10, 5, 2] is not included as the product of 100 is not strictly less than k.

Example 2:

Input: nums = [1,2,3], k = 0
Output: 0

</details>

## Code

```c
int numSubarrayProductLessThanK(int* arr, int n, int k) 
{
    if(k<=1) return 0;  // product hamesha >= 1 → answer 0; guard bina left > right ho jaata

    int left=0,right=0;
    long long prod =1;  // window product (empty = 1); long long → multiply pe overflow safe
    int res=0;
    while(right<n)
    {
        prod*=arr[right]; //keep multiplying while increasing right ;

        while(prod>=k) //keep dividing by left to reduce product.
        {
            prod/=arr[left];  // shrink: exact division (arr[left] pehle multiply hua tha)
            left++;
        }
        // [left..right] valid → [i..right], i >= left bhi valid → right-left+1 naye
        res+=(right - left +1); // after increasing right, it wil give that much subarray with product less than k
        right++;
    }
    return res;
}
```
