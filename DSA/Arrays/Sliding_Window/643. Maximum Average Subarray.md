# 643. Maximum Average Subarray I
> Length `k` wale saare subarrays mein se maximum average return karo

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Fixed sliding window](sliding_window.md) | 2 indices + running sum | O(n) | O(1) |

**How it works**
- **Soch:** Har length-`k` window ka sum alag se nikalna O(n·k) hai. Agli window pichhli se sirf do elements mein alag hai (ek aaya, ek gaya) → running sum O(1) mein update.
- **Expand:** `avg += arr[right]` (naam `avg` hai par ye window ka sum hai). Size `k+1` ho gaya to `arr[left]` minus, `left++` — fixed window mein `if` kaafi hai kyunki size ek step mein sirf 1 badhta hai.
- **Record:** Size exactly `k` ho tab `avg / k` ko `res` se compare. Divide sirf yahin hota hai.
- **Kyun sahi hai:** Har length-`k` window `right = k-1 .. n-1` pe exactly ek baar record hoti hai. Har element ek baar add, ek baar remove → O(n).
- **Dry run:** `[1,12,-5,-6,50,3], k=4`
  - `right=3`: `[1,12,-5,-6]` sum 2 → 0.5
  - `right=4`: 1 gaya → `[12,-5,-6,50]` sum 51 → **12.75**
  - `right=5`: 12 gaya → `[-5,-6,50,3]` sum 42 → 10.5 → answer 12.75 ✔

**Gotcha:** `res` `-1e18` se start hota hai, 0 se nahi — saare numbers negative hon to average bhi negative hoga (`[-1,-2,-3], k=1` → -1).
**vs related:** [GFG Max Sum Subarray of size K](<Max Sum Subarray of size K.md>) same fixed window hai, average ki jagah sum. [2461](<2461. Maximum Sum of Distinct Subarrays With Length K.md>) mein window ke elements distinct bhi hone chahiye.

<details><summary>Problem statement</summary>

You are given an integer array nums consisting of n elements, and an integer k.

Find a contiguous subarray whose length is equal to k that has the maximum average value and return this value. Any answer with a calculation error less than 10-5 will be accepted.

 

Example 1:

Input: nums = [1,12,-5,-6,50,3], k = 4
Output: 12.75000
Explanation: Maximum average is (12 - 5 - 6 + 50) / 4 = 51 / 4 = 12.75
Example 2:

Input: nums = [5], k = 1
Output: 5.00000

</details>

## Code

```c
double findMaxAverage(int* arr, int n, int k) 
{
    double res=-1e18;  // sentinel: average negative bhi ho sakta hai → 0 se start nahi
    double avg=0;  // naam avg hai par ye window ka running SUM hai
    int left = 0, right = 0;

    while (right < n)
    {
        avg += arr[right];  // expand: arr[right] window mein

        if (right - left + 1 > k)  // size k+1 → ek extra; fixed window → if kaafi
        {
            avg -= arr[left];  // shrink: arr[left] window se bahar
            left++;
        }

        if (right - left + 1 == k)  // window exactly k → record answer
        {
            double temp_avg = avg / k;  // divide sirf record karte waqt
            res = res > temp_avg ? res : temp_avg;
        }

        right++;
    }
    return res;

}
```
