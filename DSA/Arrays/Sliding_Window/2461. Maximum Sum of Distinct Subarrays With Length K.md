# 2461. Maximum Sum of Distinct Subarrays With Length K
> Length `k` ke jin subarrays ke saare elements distinct hon, unmein max sum (koi na ho to 0)

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Fixed sliding window + freq array](sliding_window.md) | `freq[100001]` + `distinct` count + running sum | O(n) | O(maxVal) |

**How it works**
- **Soch:** Window size fixed `k` hai ([643](<643. Maximum Average Subarray.md>) jaisa), bas ek extra condition: saare elements distinct. Har window mein duplicates dobara ginna O(k) hai → `freq` array aur `distinct` counter ko window ke saath slide karo.
- **Expand:** `freq[arr[right]]` 0 tha → nayi value → `distinct++`. Phir `freq++`, `sum += arr[right]`.
- **Shrink:** Size `k+1` → `freq[arr[left]]--`, 0 ho gaya to `distinct--`, `sum -= arr[left]`, `left++`.
- **Record:** `size == k && distinct == k` → koi value repeat nahi → `res = max(res, sum)`.
- **Kyun sahi hai:** Size `k` aur `k` distinct values ka matlab har value exactly ek baar. `freq`/`distinct` O(1) mein update → O(n).
- **Dry run:** `[1,5,4,2,9,9,9], k=3`
  - `[1,5,4]` → 10, `[5,4,2]` → 11, `[4,2,9]` → **15**
  - `[2,9,9]`: `distinct=2` → skip
  - `[9,9,9]`: `distinct=1` → skip → answer 15 ✔

**Gotcha:** `int freq[100001]` stack pe ~400 KB hai aur sirf LeetCode ke `1 <= nums[i] <= 10^5` constraint pe tika hai — bada value → out of bounds. `sum`/`res` `long long` hain kyunki `k * 10^5` int overflow kar sakta hai.
**vs related:** [GFG Max Sum Subarray of size K](<Max Sum Subarray of size K.md>) mein distinct wali condition nahi hai. [904](<904. Fruit Into Baskets.md>) mein yahi `freq + distinct` trick variable window pe lagti hai (`distinct <= 2`).

<details><summary>Problem statement</summary>

You are given an integer array nums and an integer k. Find the maximum subarray sum of all the subarrays of nums that meet the following conditions:

The length of the subarray is k, and
All the elements of the subarray are distinct.
Return the maximum subarray sum of all the subarrays that meet the conditions. If no subarray meets the conditions, return 0.

A subarray is a contiguous non-empty sequence of elements within an array.

 

Example 1:

Input: nums = [1,5,4,2,9,9,9], k = 3
Output: 15
Explanation: The subarrays of nums with length 3 are:
- [1,5,4] which meets the requirements and has a sum of 10.
- [5,4,2] which meets the requirements and has a sum of 11.
- [4,2,9] which meets the requirements and has a sum of 15.
- [2,9,9] which does not meet the requirements because the element 9 is repeated.
- [9,9,9] which does not meet the requirements because the element 9 is repeated.
We return 15 because it is the maximum subarray sum of all the subarrays that meet the conditions
Example 2:

Input: nums = [4,4,4], k = 3
Output: 0
Explanation: The subarrays of nums with length 3 are:
- [4,4,4] which does not meet the requirements because the element 4 is repeated.
We return 0 because no subarrays meet the conditions.

</details>

## Code

```c
long long maximumSubarraySum(int* arr, int n, int k) 
{
    long long res = 0 ;  // koi valid window nahi → 0 (problem ka rule)

    int left= 0 , right =0 ;
    long long sum =0;  // k * 10^5 tak ja sakta hai → long long

    int freq[100001] = {0};  // value → count; nums[i] <= 10^5 pe tika (~400 KB stack)
    int distinct = 0;  // window mein kitni alag values

    while (right < n)
    {
        if(freq[arr[right]]==0) distinct++;  // nayi value window mein → distinct recalculate
        freq[arr[right]]++;  // expand: freq update

        sum+=arr[right];

        if(right-left+1 > k)  // size k+1 → ek nikalo (fixed window → if kaafi)
        {
            freq[arr[left]]--;  // shrink: arr[left] window se bahar
            if(freq[arr[left]]==0) distinct--;  // value poori tarah gayi → distinct ghatao
            
            sum-=arr[left];
            left++;
        }

        if(right-left+1==k && distinct==k)  // size k + sab alag → window valid → record answer
        {
            res=sum>res?sum:res;
        }
        right++;
    }
    return res;
}
```
