# 209. Minimum Size Subarray Sum
> Sabse chhota subarray dhoondho jiska sum >= target ho (saare numbers positive)

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Variable sliding window](sliding_window.md) | 2 indices + running sum | O(n) | O(1) |

**How it works**
- **Soch:** Saare numbers positive hain → window badi karo to sum badhta hai, chhoti karo to ghatta hai. Matlab sum *monotonic* hai → sliding window lagega.
- **Expand:** `right` ko ek-ek karke aage badhao, `arr[right]` ko `sum` mein add karo. `right++` pehle hota hai, isliye window `[left, right)` hai aur length seedha `right - left`.
- **Shrink:** Jaise hi `sum >= target`, window valid hai. Ab answer chhota karne ke liye `left` se elements hatao — har step pe length record karo — jab tak window valid rahe.
- **Kyun sahi hai:** Jab `left` index `l` se aage nikal gaya, to `l` se shuru hone wali koi bhi aage wali window lambi hi hogi → `l` dobara dekhne ki zarurat nahi. Har element ek baar add, ek baar remove → O(n).
- **Dry run:** `target=7, [2,3,1,2,4,3]`
  - `[2,3,1,2]`=8 (len 4)
  - `[1,2,4]`=7 (len 3)
  - `[4,3]`=7 (len **2**) ✔

**Gotcha:** `if` nahi, `while` — ek bada element aane pe kai left elements ek saath bekaar ho jaate hain. Koi window valid na ho → `INT_MAX` → return 0.
**vs related:** [713](<713. Subarray Product Less Than K.md>) mein windows *count* karte hain (`res += right-left+1`), [1004](<1004. Max Consecutive Ones III.md>) mein window *maximize*.

<details><summary>Problem statement</summary>

Given an array of positive integers nums and a positive integer target, return the minimal length of a subarray whose sum is greater than or equal to target. If there is no such subarray, return 0 instead.


Example 1:

Input: target = 7, nums = [2,3,1,2,4,3]
Output: 2
Explanation: The subarray [4,3] has the minimal length under the problem constraint.
Example 2:

Input: target = 4, nums = [1,4,4]
Output: 1
Example 3:

Input: target = 11, nums = [1,1,1,1,1,1,1,1]
Output: 0

</details>

## Code

```c

int minSubArrayLen(int target, int* arr, int n) {
    
    int left= 0 , right=0 ;
    int sum=0, min_window=INT_MAX;  // INT_MAX = abhi tak koi valid window nahi mili
    while(right<n)
    {
        sum+=arr[right];  // expand: arr[right] window mein
        right++;  // pehle hi aage → window [left, right), length = right - left
        
        // window valid → jab tak valid hai left se shrink (minimize)
        while(sum>=target) //Do it while so that even if window with right at n-1 should also be considered, else it will not enter loop 
        {
            int cuurent_window= right-left;  // half-open window ki length
            min_window=min_window<cuurent_window?min_window:cuurent_window;  // record answer loop ke andar (window abhi valid hai)
            sum-=arr[left];  // shrink: arr[left] window se bahar
            left++;
        }
    }
    return (min_window == INT_MAX) ? 0 : min_window;  // koi window valid nahi bani → 0
}

```
