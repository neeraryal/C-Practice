# 724. Find Pivot Index
> Woh leftmost index do jiske left ke elements ka sum = right ke elements ka sum (nahi to -1)

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Prefix Sum – total minus left sum](prefix_sum.md) | None (2 sums) | O(n) | O(1) |

**How it works**
- **Soch:** Right sum alag se nikalne ki zarurat nahi: `right = total - left - arr[i]`. Ek pass mein total, doosre pass mein running left sum — prefix array bhi nahi chahiye.
- **Total:** Pehle loop mein `t_sum`.
- **Compare:** Har `i` pe `l_sum + arr[i] == t_sum - l_sum` — dono side `arr[i]` add hai, to ye `left == right` hi hai. Phir `l_sum += arr[i]`.
- **Kyun sahi hai:** Check ke waqt `l_sum` = `arr[0..i-1]` ka sum (add check ke baad hota hai). Left se scan → pehla match hi leftmost pivot. O(n), O(1).
- **Dry run:** `[1,7,3,6,5,6]`, `t_sum = 28`
  - `i=0..2`: `1 vs 28`, `8 vs 27`, `11 vs 20` → no
  - `i=3`: `l_sum=11` → `11+6 = 17 == 28-11 = 17` ✔ → **3**

**Gotcha:** `l_sum += arr[i]` check ke **baad** — pehle add kiya to `arr[i]` left mein gin jaayega. Edges apne aap handle: `i=0` pe left sum 0, last index pe right sum 0 (`[2,1,-1]` → `0`).
**vs related:** [238](<238. Product of array Except itsel.md>) bhi left/right split hai par products ke saath — division mana hai, to `total / arr[i]` trick nahi chalti, suffix alag pass mein banta hai. [560](<560.Subarray Sum Equals K.md>) prefix sums ko hash map mein store karke count karta hai.

<details><summary>Problem statement</summary>

Given an array of integers nums, calculate the pivot index of this array.

The pivot index is the index where the sum of all the numbers strictly to the left of the index is equal to the sum of all the numbers strictly to the index's right.

If the index is on the left edge of the array, then the left sum is 0 because there are no elements to the left. This also applies to the right edge of the array.

Return the leftmost pivot index. If no such index exists, return -1.

 

Example 1:

Input: nums = [1,7,3,6,5,6]
Output: 3
Explanation:
The pivot index is 3.
Left sum = nums[0] + nums[1] + nums[2] = 1 + 7 + 3 = 11
Right sum = nums[4] + nums[5] = 5 + 6 = 11
Example 2:

Input: nums = [1,2,3]
Output: -1
Explanation:
There is no index that satisfies the conditions in the problem statement.
Example 3:

Input: nums = [2,1,-1]
Output: 0
Explanation:
The pivot index is 0.
Left sum = 0 (no elements to the left of index 0)
Right sum = nums[1] + nums[2] = 1 + -1 = 0

</details>

## Code

```c
int pivotIndex(int* arr, int n) 
{
    //First Calculate the sum of array
    int t_sum =0 ; 
    for(int i=0; i< n;i++)
    {
        t_sum+=arr[i];  // total ek baar → right sum = total - left - arr[i]
    }

    //Take left sum , add current to it and comapre 
    //it with total_sum - left_sum , if match then bingo !!!

    int l_sum=0;  // l_sum = arr[0..i-1] ka sum (strictly left)
    for(int i=0 ;i<n;i++)
    {
        if(l_sum+arr[i] == t_sum -l_sum)  // dono side arr[i] add → yahi left == right check hai
            return i;  // left se scan → pehla match = leftmost pivot
        l_sum+=arr[i];  // check ke BAAD add → arr[i] apne check mein left mein nahi
    }
    return -1;
}
```
