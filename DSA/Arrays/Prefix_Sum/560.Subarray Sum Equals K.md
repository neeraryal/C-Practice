# 560. Subarray Sum Equals K
> Kitne contiguous subarrays ka sum exactly `k` hai (negatives bhi ho sakte hain)

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Prefix Sum – prefix sum + hash map count](prefix_sum.md) | Custom hash map (chaining, `MAP_SIZE` 20011): prefix sum → count | O(n) avg | O(n) |

**How it works**
- **Soch:** `sum(l..r) = prefix[r] - prefix[l-1]`. Ye `k` chahiye → `prefix[l-1] = prefix[r] - k`. Matlab har `r` pe poocho: "`sum - k` wala prefix pehle kitni baar aaya?" — ye prefix sums pe [Two Sum](<../Two_Sum/1. Two_Sum_Problem.md>) hai. Negatives hain, to sliding window nahi chalega (sum monotonic nahi).
- **Prefix:** `sum += arr[i]` (running prefix sum `arr[0..i]`).
- **Count:** `sum == k` → poora `arr[0..i]` ek answer. Phir `search(sum - k)` mila → utne saare subarrays `i` pe khatam hote hain → `res += count`.
- **Store:** `insert(sum, 1)` → is prefix sum ka count +1 (key pehle se ho to `value += 1`).
- **Kyun sahi hai:** Har subarray `arr[l..r]` exactly ek baar ginta hai — jab loop `r` pe ho aur `prefix[l-1]` map mein ho. Search insert se pehle hai, to `k=0` pe current prefix khud se empty subarray nahi banata. O(n) avg.
- **Dry run:** `[1,1,1], k=2`
  - `i=0`: `sum=1`, `search(-1)` nahi → insert `1→1`
  - `i=1`: `sum=2 == k` → `res=1`; `search(0)` nahi → insert `2→1`
  - `i=2`: `sum=3`, `search(1)` = 1 → `res=2` ✔

**Gotcha:** `if(sum == k) res++;` empty prefix (sum 0, yaani subarray index 0 se shuru) ka case hai. Cleaner: shuru mein map mein `{0:1}` seed karo (`insert(0,1)`) aur ye line hata do — same answer. Map ke nodes kabhi `free` nahi hote (leak).
**vs related:** [1. Two Sum](<../Two_Sum/1. Two_Sum_Problem.md>) jaisa complement search, par wahan `insert` mein `next = current` (NULL) collision bug hai; yahan `new_node->next = MAP[key_index]` sahi chain banata hai. [724](<724. Find Pivot Index.md>) mein ek total + left sum kaafi tha, yahan har prefix yaad rakhna padta hai.

<details><summary>Problem statement</summary>

Given an array of integers nums and an integer k, return the total number of subarrays whose sum equals to k.

A subarray is a contiguous non-empty sequence of elements within an array.

 

Example 1:

Input: nums = [1,1,1], k = 2
Output: 2
Example 2:

Input: nums = [1,2,3], k = 3
Output: 2

</details>

/*
Problem 560: Subarray Sum Equals K

Intuition kya hai? Isme hum array ko sirf ek baar left se right traverse karenge, aur chalte-chalte ek running sum banate jayenge, matlab shuru se abhi tak ka total (prefix sum).

Ab socho ki hum abhi index i pe hain aur humara total sum hai. Humein aisa subarray chahiye jiska sum k ho aur jo i pe khatam ho raha ho. Agar aisa subarray exist karta hai, to uska matlab hai ki peeche kisi point pe humara total (sum - k) tha. Kyunki us point ke baad se lekar abhi tak ka jo hissa hai, wo exactly k hai: sum - (sum - k) = k.

To humein bas ye yaad rakhna hai ki peeche kaunsa total kitni baar aaya tha. Iske liye hum map use karte hain: key = total, value = wo total kitni baar aaya. Har step pe hum map mein dekhte hain ki (sum - k) pehle kabhi aaya tha ya nahi. Agar aaya tha, to jitni baar aaya tha utne alag-alag subarrays mil gaye, kyunki har purana total ek alag starting point hai.

Do cheezein dhyaan rakhni hain. Pehli, shuru mein map mein {0: 1} daalte hain, kyunki "kuch bhi nahi liya" bhi ek prefix hai, isse wo subarrays count ho jaate hain jo index 0 se shuru hote hain. Dusri, pehle map mein search karte hain, phir current sum ko map mein daalte hain, warna k = 0 pe current sum khud se match ho jayega aur ek fake empty subarray count ho jayega.

Sliding window yahan kaam nahi karti kyunki array mein negative numbers aur zeros ho sakte hain, to window monotonic nahi rehti. Isliye prefix sum + map.

Example: [1, 2, 3], k = 3
- sum = 1: (1 - 3) = -2 map mein nahi hai. Map = {0:1, 1:1}
- sum = 3: (3 - 3) = 0 map mein hai, res = 1 ([1, 2]). Map mein 3 add.
- sum = 6: (6 - 3) = 3 map mein hai, res = 2 ([3]).

Bas ek pass mein sab ho gaya, O(n) time aur O(n) space.
*/

int subarraySum(vector<int>& arr, int k)
{
    unordered_map<long long, int> freq;    // key = prefix sum, value = kitni baar aaya
    freq[0] = 1;                           // empty prefix ek baar maan lo

    long long sum = 0;                     // running prefix sum = arr[0..i]
    int res = 0;                           // total subarrays jinka sum == k

    for (int i = 0; i < arr.size(); i++)
    {
        sum = sum + arr[i];                // current element add karo

        long long target = sum - k;        // peeche ye total aaya tha?

        if (freq.count(target) > 0)        // agar map mein target hai
        {
            res = res + freq[target];      // jitni baar aaya, utne subarrays
        }

        freq[sum] = freq[sum] + 1;         // search ke BAAD insert, current prefix record karo
    }

    return res;
}

  # define MAP_SIZE 20011  // prime size → keys buckets mein achhe se spread
  
  typedef struct Node{
      int key;              // The key to be hashed
      int value;            // The value associated with the key
      struct Node* next;    // Pointer to next node in the chain (for collision handling)
  }Node;  
  
  Node * MAP[MAP_SIZE];
  
  void initTable(void) {
      for (int i = 0; i < MAP_SIZE; i++) {
          MAP[i] = NULL;  // No chains exist initially
      }
  }
  
  int get_hash(int key )
  {
      return (key % MAP_SIZE + MAP_SIZE) % MAP_SIZE;  // prefix sum -ve ho sakta hai → index 0..MAP_SIZE-1
  }
  
  void insert(int key, int value)
  {
      // Step 1: Get the bucket index where this key should go
      int key_index = get_hash(key);
      
      // Step 2: Start from the head of the chain at this bucket
      Node* current = MAP[key_index];
      
      // Step 3: Check if key already exists in the chain
      while(current != NULL)
      {
          if(current->key == key)
          {
              // Key found - UPDATE the existing value
              current->value += value;  // += → value = is prefix sum ka count
              return;  // Exit after update
          }
          current = current->next;  // Move to next node in chain
      }
      
      // Step 4: Key not found - INSERT a new node at the head of the chain
      Node * new_node = malloc(sizeof(Node));
      new_node->value = value;
      new_node->key = key;
      new_node->next = MAP[key_index];  // Point new node to current head
      MAP[key_index] = new_node;        // Make new node the new head
      
      return;
  }
  
  int* search(int key)
  {
      // Step 1: Get the bucket index where this key should be
      int key_index = get_hash(key);
      
      // Step 2: Start from the head of the chain at this bucket
      Node * current = MAP[key_index];
      
      // Step 3: Traverse the chain looking for the key
      while(current != NULL)
      {
          if(current->key == key)
          {
              // Key found - return pointer to its value
              return &current->value;
          }
          current = current->next;  // Move to next node in chain
      }
      
      // Step 4: Key not found in the chain
      return NULL;
  }
  
  int subarraySum(int* arr, int n, int k) 
  {
      initTable();  // har call pe map reset (purane nodes free nahi hote)
      int res=0;
      int sum=0 ;
      int i=0;
  
      while (i< n)
      {
          sum +=arr[i];  // running prefix sum = arr[0..i]
          if(sum == k) res++;  // arr[0..i] khud = k (empty prefix 0 ka case; {0:1} seed se bhi)
          int * search_index= search(sum-k);  // prefix == sum-k pehle aaya? → beech ka subarray = k
          if(search_index!=NULL)
          {
              res+=*search_index;  // count add (har purana prefix ek alag subarray)
          }
          insert(sum,1);  // search ke BAAD insert → k=0 pe khud se empty subarray nahi
          i++;
      }
      return res;
  }
