# 581. Shortest Unsorted Continuous Subarray
> Sabse chhota subarray jise sort karne se poora array sorted ho jaaye — uski length do

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Prefix Sum – prefix max / suffix min scan](prefix_sum.md) | None (running max/min) | O(n) | O(1) |

**How it works**
- **Soch:** Sorted array mein har element apne left ke max se `>=` aur right ke min se `<=` hota hai. Jo element ye todta hai woh galat jagah pe hai → sort wale part mein aana hi chahiye.
- **Left → right:** Running `max_seen` (prefix max). `arr[left] < max_seen` → out of place → `right_boundary = left`. Last aisa index = right boundary.
- **Right → left:** Running `min_seen` (suffix min). `arr[right] > min_seen` → `left_boundary = right`. Last aisa (sabse left) index = left boundary.
- **Kyun sahi hai:** `right_boundary` ke baad har element apne prefix max se bada → already final jagah pe. Same `left_boundary` se pehle wale ke liye. Beech ka part sort karna zaroori aur kaafi. Do pass → O(n), copy + sort wale O(n log n) se better.
- **Dry run:** `[2,6,4,8,10,9,15]`
  - L→R: `4 < 6` → R=2; `9 < 10` → `right_boundary = 5`
  - R→L: `10 > 9` → L=4; `6 > 4` → `left_boundary = 1`
  - `5 - 1 + 1 = 5` ✔

**Gotcha:** Pehle pass ke baad `right_boundary == -1` → already sorted → `0` return (warna `-1 - (-1) + 1 = 1` aata). Comparisons strict (`<`, `>`) hain, isliye duplicates (`[1,3,2,2,2]` → `4`) sahi handle hote hain.
**vs related:** [238](<238. Product of array Except itsel.md>) bhi left pass + right pass hai, par products ke saath. Yahan sum/product ki jagah running max/min.

<details><summary>Problem statement</summary>

Given an integer array nums, you need to find one continuous subarray such that if you only sort this subarray in non-decreasing order, then the whole array will be sorted in non-decreasing order.

Return the shortest such subarray and output its length.

 

Example 1:

Input: nums = [2,6,4,8,10,9,15]
Output: 5
Explanation: You need to sort [6, 4, 8, 10, 9] in ascending order to make the whole array sorted in ascending order.
Example 2:

Input: nums = [1,2,3,4]
Output: 0
Example 3:

Input: nums = [1]
Output: 0

</details>

## Code

```
Intution : Worst case : 
1) Create a copy and sort it.
2) Now Check the first index from left where there is a mismatch, same from right, and return right-left=1 

O(n) Solution : Intution: Sorted array propery :- Every element on left is small and every element on right is bigger than current index.

1) Iterate from left to right, it should be in increasing order.
2) Store the index where , increasing order fails as it needs to be corrected.

3) Iterrate from right to left , it should be in decreasing order.
4) Store the index where, decreasing order fails as it needs to be corrected.

```

```c

int findUnsortedSubarray(int* arr, int n) {

    int left=0, right=n-1;
    int max_seen= INT_MIN,min_seen=INT_MAX;  // prefix max (L→R pass), suffix min (R→L pass)
    int right_boundary=-1, left_boundary=-1;  // -1 = abhi koi out-of-place element nahi mila
    while(left<n)
    {
        if(arr[left]<max_seen)  // left mein isse bada pada hai → ye out of place
        {
            right_boundary=left;  // last out-of-place index = right boundary
        }
        else
            max_seen=arr[left];  // sahi order → prefix max update
        left++;
    }

    if (right_boundary == -1)  // koi out of place nahi → already sorted
    return 0;
    
    while(right>=0)
    {
        if(arr[right]>min_seen)  // right mein isse chhota pada hai → out of place
        {
            left_boundary=right;  // last (sabse left) out-of-place = left boundary
        }
        else 
            min_seen=arr[right];  // suffix min update
        right--;
    }

    return right_boundary-left_boundary+1;
}

```
