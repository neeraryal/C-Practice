# 238. Product of Array Except Self
> Har `i` ke liye baaki sab elements ka product do — bina division, O(n)

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Prefix Sum – prefix × suffix products](prefix_sum.md) | Prefix product array + `res` | O(n) | O(n) extra |

**How it works**
- **Soch:** `answer[i] = (arr[0..i-1] ka product) × (arr[i+1..n-1] ka product)`. Division mana hai (aur 0 pe tootta bhi), to left aur right products alag-alag banao.
- **Prefix pass:** `right_product_prefix[i] = arr[i-1] * right_product_prefix[i-1]` — naam "right" hai par ye actually **left** products hain (`arr[0..i-1]`).
- **Suffix pass:** Right se chalo. `left_product` naam "left" hai par ye actually running **right** (suffix) product hai (`arr[i+1..n-1]`). `res[i] = left_product * prefix[i]`, phir `left_product *= arr[i]`.
- **Kyun sahi hai:** `res[i]` likhte waqt suffix mein sirf `i` ke right wale hain (multiply baad mein hota hai), prefix mein sirf left wale → `arr[i]` kahin nahi. Do pass → O(n).
- **Dry run:** `[1,2,3,4]` → prefix `[1,1,2,6]`
  - `i=3`: `1×6 = 6`, suffix → 4
  - `i=2`: `4×2 = 8`, suffix → 12; `i=1`: `12×1 = 12`, suffix → 24
  - `i=0`: `24×1 = 24` → `[24,12,8,6]` ✔

**Gotcha:** `right_product_prefix` kabhi `free` nahi hota (leak). `res[n-1]=1` aur `res_index` redundant hain — loop ka pehla step `res[n-1]` overwrite karta hai, aur `res_index` hamesha `i` ke barabar hai.
**vs related:** [724](<724. Find Pivot Index.md>) mein sum tha to `total - left` se right mil gaya; products mein division nahi, isliye suffix alag pass mein. [581](<581. Shortest Unsorted Continuous Subarray.md>) bhi left pass + right pass, par max/min ke saath.
**Better approach:** Prefix products seedha `res` mein bharo, phir right se ek running `suffix` variable se `res[i] *= suffix; suffix *= arr[i];` → O(1) extra space (output ke alawa), koi extra array nahi.

<details><summary>Problem statement</summary>

Given an integer array nums, return an array answer such that answer[i] is equal to the product of all the elements of nums except nums[i].

The product of any prefix or suffix of nums is guaranteed to fit in a 32-bit integer.

You must write an algorithm that runs in O(n) time and without using the division operation.

 

Example 1:

Input: nums = [1,2,3,4]
Output: [24,12,8,6]
Example 2:

Input: nums = [-1,1,0,-3,3]
Output: [0,0,9,0,0]

</details>

## Code

```c
int* productExceptSelf(int* arr, int n, int* returnSize) 
{

    int * right_product_prefix = calloc(n,sizeof(int));  // naam "right", par ye LEFT products hain; kabhi free nahi (leak)
    right_product_prefix[0]=1;  // index 0 ke left kuch nahi → empty product = 1
    for(int i=1 ;i<n ;i++)
    {
        right_product_prefix[i]=arr[i-1]*right_product_prefix[i-1];  // = arr[0..i-1] ka product (arr[i] khud nahi)
    }
    int* res= calloc(n,sizeof(int));
    int left_product=1, res_index=n-1;  // naam "left", par ye running RIGHT (suffix) product; res_index == i
    res[n-1]=1;  // redundant: loop ka pehla step res[n-1] overwrite karta hai
    for(int i=n-1 ; i>=0 ;i--)  // right se → suffix product saath-saath banta hai
    {
        res[res_index--]=left_product*right_product_prefix[i];  // right products × left products (arr[i] dono mein nahi)
        left_product*=arr[i];  // res likhne ke BAAD → arr[i] apne answer mein nahi aata
    }
    *returnSize=n;
    return res;
    
}
```
