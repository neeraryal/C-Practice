# 509. Fibonacci Number
> `F(n) = F(n-1) + F(n-2)`, `F(0)=0`, `F(1)=1` — `F(n)` return karo

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [1D DP – bottom-up, 2 rolling variables](1d_dp.md) | 3 `int` variables (`a`, `b`, `c`) | O(n) | O(1) |

**How it works**
- **Soch:** Plain recursion same subproblems baar-baar solve karta hai → O(2^n). `F(i)` sirf pichle do values pe depend hai, to neeche se upar banao aur sirf last 2 yaad rakho.
- **Base:** `n == 0 → 0`, `n == 1 → 1`.
- **Roll:** `a = F(i-2)`, `b = F(i-1)`; `c = a + b`, phir window slide: `a = b`, `b = c`.
- **Kyun sahi hai:** Har iteration ke baad `a = F(i-1)`, `b = F(i)`. Loop `i = n` pe khatam → `b = F(n)`. O(n) time, O(1) space.
- **Dry run:** `n=4`
  - `i=2`: c=1 → a=1, b=1
  - `i=3`: c=2 → a=1, b=2
  - `i=4`: c=3 → a=2, b=3 → `3` ✔

**Gotcha:** `n == 0` check zaroori hai — loop `n=0` pe nahi chalta aur `b=1` galat return hota (`n == 1` wala check redundant hai, loop ke bina bhi `b=1`). `int` `F(47)` pe overflow hota hai; LeetCode `n ≤ 30` deta hai to safe.
**vs related:** [53](<../../Arrays/Kadane/53. Maximum Subarray(Kadanes).md>) (Kadane) bhi 1D DP hai jisme sirf last state yaad rakhte hain — wahan `best_ending_here`, yahan last 2 Fibonacci values.
**Better approach:** `[[1,1],[1,0]]^n` ko fast power (repeated squaring) se nikaalo → O(log n) time; `n ≤ 30` pe farak nahi padta.

<details><summary>Problem statement</summary>

The Fibonacci numbers, commonly denoted F(n) form a sequence, called the Fibonacci sequence, such that each number is the sum of the two preceding ones, starting from 0 and 1. That is,

F(0) = 0, F(1) = 1
F(n) = F(n - 1) + F(n - 2), for n > 1.
Given n, calculate F(n).

 

Example 1:

Input: n = 2
Output: 1
Explanation: F(2) = F(1) + F(0) = 1 + 0 = 1.
Example 2:

Input: n = 3
Output: 2
Explanation: F(3) = F(2) + F(1) = 1 + 1 = 2.
Example 3:

Input: n = 4
Output: 3
Explanation: F(4) = F(3) + F(2) = 2 + 1 = 3.

</details>

## Code

```c
int fib(int n)
{
    if(n==0) return 0;  // base case — loop n=0 pe nahi chalta, b=1 galat aata
    if (n==1) return 1;

    int a=0 , b=1 ,c=0;  // a = F(i-2), b = F(i-1) — sirf last 2 chahiye
    for (int i=2;i<=n;i++)  // F(2) se F(n) tak bottom-up
    {
        c=a+b;  // F(i) = F(i-1) + F(i-2)
        a=b;  // window slide: purana F(i-1) ab F(i-2)
        b=c;  // b = F(i)
    }
return b;  // loop ke baad b = F(n)
}
```
