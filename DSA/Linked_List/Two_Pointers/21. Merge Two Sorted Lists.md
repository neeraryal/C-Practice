# 21. Merge Two Sorted Lists
> Do sorted lists ke nodes ko splice karke ek sorted list banao (naye nodes nahi)

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Two Pointers – merge by splicing runs](two_pointers.md) | 2 singly linked lists, ek pointer har list pe (no dummy) | O(n + m) | O(1) |

**How it works**
- **Soch:** Dono lists pe ek-ek pointer. `l1` = "current" list (jiske nodes abhi result mein ja rahe hain), `l2` = doosri. `l1` ke jitne nodes `l2` ke head se chhote/barabar hain, wo poora **run** already sahi order mein juda hai → bas run ke end pe `l2` jodo aur roles swap kar do.
- **Setup:** Koi list empty → doosri return. `l1->val > l2->val` ho to swap → `l1` ka head chhota → `res = l1` hi final head.
- **Run:** `while (l1 && l1->val <= l2->val)` → `temp` = run ka last node, `l1` aage.
- **Splice + swap:** `temp->next = l2` (run ke baad doosri list), phir `l1`, `l2` swap — ab doosri list current hai aur uska head pichhle run ke baad wale node se chhota hai.
- **Kyun sahi hai:** Swap ke baad hamesha naye `l1` ka head `<=` naye `l2` ka head (shuru mein swap se, baad mein run ki stop condition se) → har run kam se kam 1 node ka, `temp` kabhi NULL nahi. Ek list khatam (`l1` NULL) → swap ke baad `l2` NULL → loop band, aur last splice baaki list jod chuka hai. Har node ek baar → O(n+m), O(1).
- **Dry run:** list1 `[1a,2a,4a]`, list2 `[1b,3b,4b]`
  - `1a > 1b`? nahi → no swap, `res = 1a`
  - run `1a` → `1a->1b`, swap; run `1b` → `1b->2a`, swap
  - run `2a` → `2a->3b`, swap; run `3b,4b` (`4b <= 4a`) → `4b->4a`, swap
  - `l2` NULL → `[1,1,2,3,4,4]` ✔

**Gotcha:** Inner loop ka `<=` zaroori hai — `<` hota to equal heads (`[1]` + `[1]`) pe run 0 node ka → `temp` NULL → `temp->next` crash (test kiya: SEGV). Pehli line `if(!list1 && !list2)` zaroori hai — agli do checks `&& list2` / `&& list1` ki wajah se `[] + []` pe match nahi karti.
**vs related:** Common tareeka `dummy` + `tail` hai — har step dono heads mein se chhota node `tail->next` pe (node-by-node). Ye splice version run-by-run jodta hai: same O(n+m)/O(1), bas dummy node nahi. [83](<83. Remove Duplicates from Sorted List.md>) mein ek list pe read/write pointers the, yahan do lists pe ek-ek pointer.

## Code

```c
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
typedef struct ListNode Node ;
struct ListNode* mergeTwoLists(struct ListNode* list1, struct ListNode* list2) 
{
    if(!list1 && !list2) return NULL;  // zaroori: agli do checks dono empty pe match nahi karti → l1->val NULL deref
    if ( !list1 && list2 ) return list2;  // ek list empty → doosri hi answer
    if ( !list2 && list1 ) return list1;

    Node * l1 = list1;
    Node * l2 = list2;

    if (l1->val > l2->val )  // l1 = chhote head wali list → wahi result ka head
    {
        l1=list2;
        l2=list1;
    }
    Node * res= l1;  // final head yahin fix (chhota head)
    while (l1 && l2)  // swap ke baad l2 NULL → baaki list already juda hai
    {
        Node* temp =NULL;  // temp = current run ka last node
        while (l1 && l1->val <= l2->val )  // run: l2 head se chhote/barabar nodes as-is; <= se run >= 1 node
        {
            temp = l1;
            l1= l1->next;
        }
        temp->next= l2;  // splice: run ke baad doosri list jodo (temp kabhi NULL nahi)
        Node * swap_temp=NULL;
        swap_temp= l1;  // roles swap: doosri list current, uska head ab chhota
        l1=l2;
        l2=swap_temp; 
    }
    return res;
}
```
