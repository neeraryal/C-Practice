# 141. Linked List Cycle
> Batao linked list mein cycle hai ya nahi

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Fast & Slow – Floyd cycle detection](fast_slow.md) | Singly linked list, 2 node pointers | O(n) | O(1) |

**How it works**
- **Soch:** Cycle nahi hai to `fast` NULL tak pahunch jaayega. Cycle hai to dono cycle mein phas jaate hain aur `fast` har step `slow` se 1 node paas aata hai → kabhi na kabhi same node pe milenge (track pe tez runner slow wale ko lap kar deta hai).
- **Move:** `slow` 1 step, `fast` 2 step, jab tak `fast && fast->next`.
- **Check:** Har move ke **baad** `slow == fast` → cycle ✔. Loop normally khatam → `fast` end tak pahuncha → no cycle.
- **Kyun sahi hai:** Cycle ke andar gap har step exactly 1 se ghatta hai, to `fast` `slow` ko skip karke aage nahi nikal sakta — gap 0 hote hi milte hain. `slow` cycle mein ek lap poora karne se pehle pakda jaata hai → O(n), aur hash set nahi chahiye → O(1).
- **Dry run:** `[3,2,0,-4]`, tail → index 1 (node `2`)
  - step 1: `s=2, f=0`
  - step 2: `s=0, f=2` (`-4 → 2` se ghoom ke)
  - step 3: `s=-4, f=-4` → `slow == fast` → `true` ✔

**Gotcha:** Nodes (addresses) compare karo, values nahi — duplicate values se galat match hoga. Shuru ka `if (!head || !head->next)` guard redundant hai — `fast && fast->next` loop condition ye cases already handle karti hai (guard hata ke bhi same output).

## Code

```c
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */

typedef struct ListNode Node;
bool hasCycle(struct ListNode *head)
{
    if ( !head || !head->next) return false ;  // empty / akela node bina self-loop → no cycle (redundant: loop bhi yahi karta)
    Node * slow = head;  // dono head se: slow 1 step, fast 2 step
    Node * fast = head;

    while(fast && fast ->next)  // fast end tak pahuncha → list khatam → no cycle
    {
        slow = slow->next;
        fast = fast->next->next;  // cycle mein har step gap 1 se ghatta hai → skip nahi

        if(slow == fast)  // move ke BAAD check (start mein dono head pe hain); address compare
            return true ;
        
    }
    return false ;
}
```
