# 19. Remove Nth Node From End of List
> List ke end se n-th node hatao aur head return karo (ek pass mein)

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Fast & Slow – fixed gap of n](fast_slow.md) | Singly linked list, dummy node + 2 pointers | O(L) | O(1) |

**How it works**
- **Soch:** End se n-th = start se `(L-n+1)`-th, par length L pata nahi. Speed 2x ki jagah **gap** fix karo: `f` ko pehle n step aage bhejo, phir dono saath 1-1 step. `f` last node pe pahunche tab `s` hatane wale node ke **just pehle** hoga.
- **Dummy:** `dummy->next = head`, dono pointers `dummy` se start. Isse head delete (n = L) bhi normal case — `s` dummy pe hi rukta hai.
- **Gap banao:** `for` loop se `f` n step aage.
- **Move:** `while (f->next)` → `f`, `s` dono 1 step. Rukne pe `s->next = s->next->next` se target unlink.
- **Kyun sahi hai:** Gap hamesha n rehta hai. `f` last node (dummy = index 0, to last = index L) pe → `s` index `L-n` pe = target `L-n+1` ka predecessor. Ek pass, O(1).
- **Dry run:** `[1,2,3,4,5], n=2`
  - gap: `f=2`, `s=dummy`
  - move: `s=1,f=3` → `s=2,f=4` → `s=3,f=5` (`f->next` NULL, stop)
  - `3->next = 5` → `[1,2,3,5]` ✔

**Gotcha:** `dummy` aur hataya gaya node dono kabhi `free` nahi hote → memory leak (ASan: 2 allocations; LeetCode pe chalta hai). Code `n <= L` constraint pe tika hai — `n > L` pe `f` NULL ho ke deref crash.
**vs related:** [876](<876. Middle of the Linked List.md>)/[141](<141. Linked List Cycle.md>) mein speed ka farak (2x) hai, yahan same speed + fixed distance. Dummy wala trick [24](<../Reversal/24. Swap Nodes in Pairs.md>) mein bhi head-pair ke liye hai.

## Code

```c
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
typedef struct ListNode Node;
struct ListNode* removeNthFromEnd(struct ListNode* head, int n) {
    Node * dummy= malloc ( sizeof(Node));  // dummy → head delete bhi normal case (free nahi hota → leak)
    dummy-> next=head;
    Node * s = dummy , * f = dummy;  // dono dummy se → s target ke predecessor pe rukega
    for(int i=0 ; i< n ; i++)  // f ko n step aage → s-f gap = n (n > L hota to NULL deref)
    {
        f= f->next ;
    }

    while (f->next)  // f last node pe ruke → s target se ek pehle
    {
        f=f->next;  // gap fix rakhne ke liye dono 1-1 step
        s=s->next;
    }

    s->next =s->next->next;  // target unlink (removed node free nahi hota → leak)
    return dummy->next;  // head hi delete hua ho to bhi sahi naya head
}
```
