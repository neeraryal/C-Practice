# 876. Middle of the Linked List
> Linked list ka middle node return karo — do middle hon to second wala

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Fast & Slow – fast 2x, slow middle pe](fast_slow.md) | Singly linked list, 2 node pointers | O(n) | O(1) |

**How it works**
- **Soch:** Length pata nahi aur do pass nahi karne. `f` har step 2 node chale aur `s` 1 node, to jab `f` end pe pahunchega tab `s` ne aadha hi raasta tay kiya hoga → `s` = middle.
- **Move:** `s = s->next`, `f = f->next->next` jab tak `f && f->next` hai.
- **Stop:** Odd length → `f` last node pe rukta hai (`f->next == NULL`). Even length → `f` NULL ho jaata hai aur `s` second middle pe hota hai.
- **Kyun sahi hai:** k steps ke baad `s` index k pe, `f` index 2k pe. Loop tab rukta hai jab `2k >= n-1`, yaani `k = n/2` (integer division) → exactly (second) middle. Ek pass, O(1).
- **Dry run:** `[1,2,3,4,5]`
  - start `s=1, f=1`
  - step 1: `s=2, f=3`
  - step 2: `s=3, f=5` → `f->next` NULL, stop → `[3,4,5]` ✔

**Gotcha:** Condition mein `f && f->next` dono chahiye — `f` check even length ke liye, `f->next` check `f->next->next` deref safe karne ke liye. First middle chahiye to `while (f->next && f->next->next)` lagao.
**vs related:** Yahi middle-finder [234](<234. Palindrome Linked List.md>) ka step 1 hai. [141](<141. Linked List Cycle.md>) mein same 2x speed cycle pakadne ke liye use hoti hai.

## Code

```c
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
typedef struct ListNode Node;
struct ListNode* middleNode(struct ListNode* head) 
{
    Node *s = head, *f = head;  // dono head se: s 1 step, f 2 step chalega

    while (f && f->next)  // f NULL (even) ya last node (odd) → s middle pe
    {
        s= s->next;  // slow: 1 step
        f= f->next->next;  // fast: 2 step → f ne 2k, s ne k nodes cover kiye
    }
    return s;  // even length mein ye second middle hai
}
```
