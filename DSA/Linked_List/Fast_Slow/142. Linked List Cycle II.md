# 142. Linked List Cycle II
> Cycle jis node se shuru hota hai wo return karo, cycle nahi to NULL (list modify nahi karni)

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Fast & Slow – Floyd + entry find](fast_slow.md) | Singly linked list, 2 node pointers | O(n) | O(1) |

**How it works**
- **Soch:** Phase 1 bilkul [141](<141. Linked List Cycle.md>) hai — slow/fast mile to cycle pakka. Phir math trick: head se cycle entry ki doori = meeting point se aage entry ki doori (poore laps chhod ke).
- **Phase 1 (detect):** `slow` 1 step, `fast` 2 step jab tak mil na jaayein. `fast` NULL tak pahuncha → `NULL` return.
- **Phase 2 (entry):** Milte hi `slow = head`, `fast` meeting point pe hi rahe. Ab **dono 1-1 step** chalo — jahan milenge wahi cycle ka start.
- **Kyun sahi hai:** `a` = head → entry, `b` = entry → meeting, `c` = meeting → entry (cycle `L = b + c`). Fast ne double chala: `2(a+b) = a+b + kL` → `a+b = kL` → `a = (k-1)L + c`. Yaani head se `a` step = meeting se `c` step + poore laps → dono entry pe hi milte hain. O(n), O(1).
- **Dry run:** `[3,2,0,-4]`, tail → index 1
  - Phase 1 (141 jaisa): `slow = fast = -4` pe mile (`a=1`, `b=2`, `c=1`)
  - Phase 2: `slow=3` (head), `fast=-4` → 1 step: `slow=2`, `fast=2`
  - Mil gaye → node `2` (index 1) ✔

**Gotcha:** Phase 2 mein `fast` bhi **1 step** chalta hai, 2 nahi. Poori list hi cycle ho (`[1,2]`, pos 0) to dono head pe hi milte hain → inner `while` chalta hi nahi aur `head` return — sahi (`a = 0`).
**vs related:** [141](<141. Linked List Cycle.md>) sirf phase 1 hai (true/false). Hash set se bhi entry milti hai (pehla repeat node) par O(n) space — Floyd O(1) mein karta hai, aur list modify bhi nahi karta.

<h2><a href="https://leetcode.com/problems/linked-list-cycle-ii">142. Linked List Cycle II</a></h2><h3>Medium</h3><hr><p>Given the <code>head</code> of a linked list, return <em>the node where the cycle begins. If there is no cycle, return </em><code>null</code>.</p>

<p>There is a cycle in a linked list if there is some node in the list that can be reached again by continuously following the <code>next</code> pointer. Internally, <code>pos</code> is used to denote the index of the node that tail&#39;s <code>next</code> pointer is connected to (<strong>0-indexed</strong>). It is <code>-1</code> if there is no cycle. <strong>Note that</strong> <code>pos</code> <strong>is not passed as a parameter</strong>.</p>

<p><strong>Do not modify</strong> the linked list.</p>

## Code

```c
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
typedef struct ListNode Node;
struct ListNode *detectCycle(struct ListNode *head) {
    Node * slow = head;  // phase 1 (141 jaisa): slow 1 step, fast 2 step
    Node * fast = head;

    while(fast && fast ->next)  // fast end tak pahuncha → cycle nahi
    {
        slow = slow->next;
        fast = fast->next->next;

        if(slow == fast)  // mile → cycle pakka, ab entry dhoondho
        {
            slow=head;  // phase 2: slow head pe, fast meeting point pe hi
            while(slow !=fast)  // a = (k-1)L + c → dono entry pe hi milenge
            {
                slow =slow->next;
                fast = fast->next;  // phase 2 mein fast bhi sirf 1 step
            }
                return slow ;  // cycle ka start node
        }
    }
    return NULL;  // loop normally khatam → no cycle
}
```
