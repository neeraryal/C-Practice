# 234. Palindrome Linked List
> Singly linked list palindrome hai ya nahi — O(n) time, O(1) space mein

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Fast & Slow – middle + reverse second half](fast_slow.md) | Singly linked list, in-place reversal | O(n) | O(1) |

**How it works**
- **Soch:** Array hota to dono ends se compare kar lete. List mein peeche nahi ja sakte → second half ko hi ulta kar do, phir dono halves ko aage-aage compare karo.
- **Find middle:** [876](<876. Middle of the Linked List.md>) wala slow/fast → `slow` = second middle = second half ka start.
- **Reverse:** `slow` se end tak [206](<../Reversal/206. Reverse Linked List.md>) wala prev/curr/next loop → `prev` = reversed half ka head (original tail).
- **Compare:** `left_head = head`, `right_head = prev`; jab tak `right_head` hai, values match karo. Ek bhi mismatch → `false`.
- **Kyun sahi hai:** Right half mein `ceil(n/2)` nodes hain aur left se utne nodes hamesha milte hain (first half ka last node ab bhi `slow` node ko point karta hai), to har mirror pair check hota hai. Odd length mein middle khud se compare hota hai — harmless. Teen O(n) pass, O(1) space.
- **Dry run:** `[1,2,2,1]`
  - middle: `slow` = index 2 (`2`)
  - reverse `2->1` → `1->2`, `right_head = 1`
  - compare `1==1`, `2==2` → `right_head` NULL → `true` ✔

**Gotcha:** Function list ko modified chhod deta hai — second half reversed rehta hai (`[1,2,2,1]` ke baad head se sirf `[1,2,2]` dikhta hai). Caller ko list wapas chahiye to compare ke baad second half dobara reverse karo.
**vs related:** [876](<876. Middle of the Linked List.md>) (middle) + [206](<../Reversal/206. Reverse Linked List.md>) (reverse) ka combo. [125](<../../Strings/Two_Pointers/125. Valid Palindrome.md>) mein string pe seedha dono ends se two pointers chal jaate hain.

## Code

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
typedef ListNode Node;
class Solution {
public:
    bool isPalindrome(ListNode* head) 
    {
        if(!head || !head->next) return true;  // 0/1 node → hamesha palindrome
        //1 Find the Middle 
        Node* slow = head;  // 876 wala middle finder: slow 1, fast 2 step
        Node* fast = head;
        while(fast && fast->next)  // loop ke baad slow = second middle = right half ka start
        {
            slow=slow->next;
            fast=fast->next->next;
        }
        // Reverse second half
        Node* prev= NULL;
        Node* curr=slow;  // slow se end tak (right half) reverse karna hai
        while(curr)
        {
            ListNode* next= curr->next;  // link todne se pehle aage ka part save
            curr->next= prev;  // link ulta (206 jaisa)
            prev=curr;
            curr=next;
        }

        //Compare both halves
        Node* right_head=prev;  // prev = reversed half ka head (original tail)
        Node* left_head=head;
        while(right_head)  // right half chhota/barabar → uske khatam hone tak compare
        {
            if(right_head->val != left_head->val) return false;  // mirror pair mismatch → palindrome nahi
            right_head=right_head->next;
            left_head=left_head->next;
        }
        return true;  // note: list modified rehti hai (right half reversed)
    }
};
```
