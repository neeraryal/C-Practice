# 24. Swap Nodes in Pairs
> Har do adjacent nodes swap karo — values nahi, nodes ke links badalne hain

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Reversal – pairwise relink with dummy](reversal.md) | Singly linked list, dummy + 3 pointers | O(n) | O(1) |

**How it works**
- **Soch:** Har pair `first -> second` ko `second -> first` banana hai aur pichhle part ko naye pair ke head (`second`) se jodna hai. Pehle pair ke peeche koi node nahi → `dummy` laga do, to head wala pair bhi normal case.
- **Pick pair:** `prev` = pair se just pehle wala node. `first = prev->next`, `second = first->next`.
- **Relink (3 links):** `first->next = second->next` (pair ke baad wali list bachao), `second->next = first` (swap), `prev->next = second` (pichhla part naye pair se juda).
- **Jump:** `prev = first` — swap ke baad `first` pair ka last node hai → agle pair ka predecessor. 2 nodes aage.
- **Kyun sahi hai:** Loop tabhi chalta hai jab `prev` ke baad poore 2 nodes hon; odd length ka akela last node as-is reh jaata hai. Har node ek baar → O(n), O(1).
- **Dry run:** `[1,2,3,4]`
  - `prev=dummy`: `1,2` swap → `dummy->2->1->3->4`, `prev=1`
  - `prev=1`: `3,4` swap → `2->1->4->3`, `prev=3`
  - `prev->next` NULL → return `dummy->next` → `[2,1,4,3]` ✔

**Gotcha:** `first->next = second->next` ko `second->next = first` se pehle likhna zaroori — warna baaki list ka pointer overwrite ho ke kho jaata hai. `dummy` kabhi `free` nahi hota → memory leak (ASan confirm; LeetCode pe chalta hai).

## Code

```c
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
typedef struct ListNode Node;
struct ListNode* swapPairs(struct ListNode* head) 
{
    if( ! head || ! head->next) return head;  // 0/1 node → swap ko kuch nahi (malloc bhi bacha)

    Node * dummy = malloc( sizeof( Node));  // dummy → head wala pair bhi normal case (free nahi hota → leak)
    dummy -> next = head;

    Node * prev = dummy;  // prev = current pair se just pehle wala node

    while ( prev->next && prev->next->next )  // poore 2 nodes bache hon tabhi swap; akela node as-is
    {
        Node * first = prev-> next;
        Node * second = first -> next ; 

        first->next=second->next;  // pair ke baad ki list first se jodo — ye sabse pehle, warna kho jaati
        second->next= first;  // swap: second aage
        prev->next=second;  // pichhla part naye pair ke head se juda

        prev=first;  // first ab pair ka last → agle pair ka predecessor
    }
    return dummy->next;  // naya head = purana second node
}
```
