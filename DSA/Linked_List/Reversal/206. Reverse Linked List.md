# 206. Reverse Linked List
> Singly linked list ko ulta karo aur naya head return karo

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Reversal – prev/curr/next 3-pointer](reversal.md) | Singly linked list, 3 node pointers | O(n) | O(1) |

**How it works**
- **Soch:** Har node ka `next` pichhle node ki taraf mod do. Par jaise hi `current->next` badla, aage ki list ka raasta kho jaata hai → isliye pehle `next` mein save karo.
- **Save:** `next = current->next` (aage ka part bachao).
- **Flip:** `current->next = prev` (link ulta).
- **Advance:** `prev = current`, `current = next` — dono ek step aage.
- **Kyun sahi hai:** Invariant: `prev` = ab tak reverse hue part ka head, `current` = baaki original list ka head. `current` NULL → poori list reverse, `prev` = naya head (purana tail). Har node ek baar → O(n), O(1).
- **Dry run:** `[1,2,3,4,5]`
  - `cur=1`: `1->NULL`, `prev=1`
  - `cur=2`: `2->1`, `prev=2` … `cur=5`: `5->4`, `prev=5`
  - `current` NULL → return `prev` → `[5,4,3,2,1]` ✔

**Gotcha:** Return `prev` karo, `current` nahi (loop ke baad wo NULL hai). Empty list pe loop chalta hi nahi → `NULL` return, sahi. Save se pehle flip kiya to baaki list gum.

## Code

```c
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
typedef struct ListNode Node; 
struct ListNode* reverseList(struct ListNode* head) 
{
    Node * current =head;
    Node * next =NULL;
    Node * prev = NULL;  // reversed part ka head; NULL se start → purana head tail banega
    while ( current )  // current NULL → poori list reverse ho gayi
    {
        next= current->next;  // save: link todne se pehle aage ka part bachao
        current -> next= prev;  // flip: link ulta
        prev= current;  // advance: dono pointer ek step aage
        current= next;
    }
    return prev;  // prev = naya head (purana tail); current NULL hai
}
```
