# 1903. Largest Odd Number in String
> Digit string ka sabse bada odd-valued substring do (koi nahi to `""`)

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Simulation – right se scan](simulation.md) | Ek index `right` + `string res` | O(n) | O(n) (output) |

**How it works**
- **Soch:** Number odd hai ya nahi sirf **last digit** decide karta hai. Sabse bada odd substring = sabse lamba prefix jo odd digit pe khatam ho (leading zeros nahi → lamba = bada). To right se pehla odd digit dhoondho; `num[0..right]` hi answer.
- **Scan:** `right = n-1` se peeche; even digit → `right--`.
- **Cut:** Odd mila → `res.append(num, 0, right+1)` aur `break`. Koi odd nahi → `res` khaali `""`.
- **Kyun sahi hai:** Answer odd digit pe hi khatam ho sakta hai, aur rightmost odd digit tak ka prefix har odd-ending substring se lamba-ya-barabar hai; `num[0]` non-zero hai to lamba = bada. Worst case ek scan → O(n).
- **Dry run:** `num="52"`
  - `right=1`: `'2'` even → `right=0`
  - `right=0`: `'5'` odd → `num[0..0]` = `"5"` ✔
  - (`"4206"` → koi odd nahi → `""`)

**Gotcha:** String ko `int`/`long` mein convert mat karo — length 10⁵ tak hai, overflow. "Lamba prefix = bada number" sirf isliye sahi hai ki input mein leading zeros nahi hain.

## Code

```cpp
class Solution {
public:
    string largestOddNumber(string num) 
    {
        int right = num.size()-1;  // right se scan → odd/even sirf last digit decide karta hai
        string res;
        while(right>=0) 
        {
            if ((num[right] - '0') % 2 == 0) right --;  // even digit pe khatam number even → isse pehle tak dekho
            else
            {
                res.append(num,0,right+1);  // rightmost odd digit tak poora prefix = sabse bada odd
                break;
            }
        }   
        return res;  // koi odd digit nahi → "" hi return
    }
};
```
