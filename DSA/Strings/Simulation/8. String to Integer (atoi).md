# 8. String to Integer (atoi)
> String ko 32-bit signed int mein badlo: spaces skip, sign, digits, range ke bahar clamp

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Simulation – parse with overflow guard](simulation.md) | `int res`, `sign`, index `i` | O(n) | O(1) |

**How it works**
- **Soch:** Problem khud steps deti hai — bas unhe order mein follow karo: spaces → sign → digits → clamp. Asli trick overflow ko `long` ke bina, multiply se **pehle** pakadna hai.
- **Skip + sign:** `while(s[i]==' ') i++`, phir ek hi `'+'`/`'-'` allowed → `sign` set, `i++`.
- **Digits:** Jab tak `'0'..'9'`: `res = res*10 + digit`. Pehle non-digit (ya `'\0'`) pe ruk jao.
- **Overflow guard:** `res > INT_MAX/10` → `*10` hi overflow karega; `res == INT_MAX/10 && digit > 7` → `2147483647` se upar. Dono pe `sign` dekh ke `INT_MAX`/`INT_MIN` return.
- **Kyun sahi hai:** Guard ki wajah se `res` kabhi `INT_MAX` se upar nahi jaata → `res*sign` safe. `-2147483648` pe last digit `8 > 7` → `INT_MIN` return hota hai, jo exact answer hi hai, isliye ek hi guard dono signs ke liye chalta hai. Ek pass → O(n).
- **Dry run:** `s=" -042"` (Example 2)
  - space skip → `'-'` → `sign=-1`, `i=2`
  - `'0'` → 0, `'4'` → 4, `'2'` → 42; `'\0'` pe stop → `-42` ✔
  - `"-91283472332"`: `res=912834723 > 214748364` → `INT_MIN` ✔

**Gotcha:** Loops mein bounds check nahi hai — C++11 se `s[s.size()]` `'\0'` deta hai, to `""`, `"   "`, `"+"` pe loops wahin ruk jaate hain (sab `0`). Sirf `' '` skip hota hai (problem whitespace = space hi define karti hai). `n` unused hai (nit).
**vs related:** [1903](<1903. Largest Odd Number in String.md>) number banata hi nahi, sirf last odd digit dhoondhta hai. [66](<../../Arrays/Simulation/66. PlusOne.md>) bhi digit-by-digit kaam hai, par right se carry ke saath.

<p>The algorithm for <code>myAtoi(string s)</code> is as follows:</p>

<ol>
	<li><strong>Whitespace</strong>: Ignore any leading whitespace (<code>&quot; &quot;</code>).</li>
	<li><strong>Signedness</strong>: Determine the sign by checking if the next character is <code>&#39;-&#39;</code> or <code>&#39;+&#39;</code>, assuming positivity if neither present.</li>
	<li><strong>Conversion</strong>: Read the integer by skipping leading zeros&nbsp;until a non-digit character is encountered or the end of the string is reached. If no digits were read, then the result is 0.</li>
	<li><strong>Rounding</strong>: If the integer is out of the 32-bit signed integer range <code>[-2<sup>31</sup>, 2<sup>31</sup> - 1]</code>, then round the integer to remain in the range. </ol>

## Code

```cpp
class Solution {
public:
    int myAtoi(string s) 
    {
        int n= s.size();  // unused (nit)
        int i=0;
        int sign = 1;
        int res=0;
        while(s[i]==' ') i++;  // leading spaces skip; s[size()] == '\0' (C++11) → yahin rukta hai

        if(s[i] == '+' ||  s[i] == '-')  // sirf ek sign allowed → "+-12" pe digits loop turant rukta → 0
        {
            if(s[i]=='-')
                sign=-1;
            i++;
        }

        while(s[i]>= '0' && s[i]<='9')  // pehle non-digit (ya '\0') pe parse khatam
        {
            int temp = s[i]-'0';

            if(res>INT_MAX/10 || (res== INT_MAX/10 && temp>7))  // overflow multiply se PEHLE pakdo (INT_MAX = 2147483647)
            {
                return sign==1?INT_MAX:INT_MIN;  // clamp; "-2147483648" pe INT_MIN hi exact answer
            }

            res=(res*10)+temp;  // guard ke baad safe: res <= INT_MAX
            i++;
        }
        return res*sign;  // res kabhi INT_MAX se upar nahi → negate safe
        
    }
};
```
