# 567. Permutation in String
> Check karo ki `s2` mein `s1` ka koi permutation (anagram) substring ki tarah maujood hai ya nahi

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Fixed sliding window – freq signature match](sliding_window.md) | `count_arr[26]` (calloc) | O(26·n) | O(1) (26 ints) |

**How it works**
- **Soch:** Permutation = same length + same char counts. To `s2` pe `len(s1)` size ki fixed window chalao aur dekho kabhi window ka freq `s1` ke freq jaisa hota hai ya nahi.
- **Setup:** `count_arr` mein `s1` ke counts `+` karo. Window mein aaya har char `-` karega → saare 26 zero = exact match.
- **Slide:** `s2[index]` ko `--` (expand). `index >= character_count` ho to `s2[index - character_count]` ko `++` (shrink: left wala bahar). Phir 26 entries scan — sab 0 → `true`.
- **Approach 2:** Variable window + `matched` counter. `matched_frequency[c] > frequency[c]` hote hi left se shrink, to window mein kabhi extra char nahi rehta → `matched == required` matlab exact permutation. 26-scan nahi → O(n).
- **Approach 3:** Approach 2 hi, ek array mein: `freq_arr[c]` = "abhi kitne aur chahiye"; `< 0` hua (extra char) to shrink. `matched == strlen(s1)` pe `true`.
- **Kyun sahi hai:** Pehle `len(s1)` steps ke baad window hamesha exactly `len(s1)` ki hai, aur sab-zero tabhi hota hai jab counts barabar hon. n windows × 26 check → O(26·n) = O(n).
- **Dry run:** `s1="ab", s2="eidbaooo"` (approach 1)
  - `index=2` (`d`): `e` bahar → window `id`
  - `index=3` (`b`): `i` bahar → window `db` (`d=-1, a=1` abhi bache)
  - `index=4` (`a`): `d` bahar → window `ba` → sab 0 → `true` ✔

**Gotcha:** Approach 1 mein `return true` se pehle `count_arr` free nahi hota → memory leak (sirf false wale path pe `free` hai). Approach 3 mein `strlen(s1)` loop ke andar har iteration chalta hai → O(n·m); ek baar bahar compute karo.
**vs related:** [76](<76. Minimum Window Substring.md>) mein yahi `matched`/`required` idea hai, par window size fixed nahi, extra chars allowed hain aur window minimize karni hai. [Max Sum Subarray of size K](<../../Arrays/Sliding_Window/Max Sum Subarray of size K.md>) wahi fixed window hai, bas state sum hai, freq nahi.

<details><summary>Problem statement</summary>

Given two strings s1 and s2, return true if s2 contains a permutation of s1, or false otherwise.

In other words, return true if one of s1's permutations is the substring of s2.

 

Example 1:

Input: s1 = "ab", s2 = "eidbaooo"
Output: true
Explanation: s2 contains one permutation of s1 ("ba").
Example 2:

Input: s1 = "ab", s2 = "eidboaoo"
Output: false

</details>

## Code

```c
bool checkInclusion(char* s1, char* s2) {
    int * count_arr= calloc(26, sizeof(int));  // s1 ke counts (+) minus window ke counts (-) → sab 0 = match
    int character_count=0;
    for (int i=0 ;s1[i]!='\0';i++)
    {
        count_arr[s1[i]-'a']++;
        character_count++;  // = len(s1) = fixed window size
    }
    int index=0;
    while(s2[index]!='\0')
    {
        count_arr[s2[index]-'a']--;  // expand: s2[index] window mein → count ghatao
        if(index>=character_count) //If window length rech or exceeds, we maintin it.
        {
            count_arr[s2[index-character_count]-'a']++;  // shrink: window se bahar gaya char → count wapas
        }
        int i=0;
        while(i<26)//We rechek after ading and maintaining window that all are inside window, if yes then all will be 0.
        {
            if(count_arr[i]!=0) break;
            i++;
        }
        // Gotcha: yahan return se pehle count_arr free nahi hota → memory leak
        if(i==26) return true; //If all are 0, that means current window has s1 in in it.
        index++;
    }
    free(count_arr);
    return false;
    
}
```


```c
bool checkInclusion(char* s1, char* s2) {
    int * frequency=calloc(26,sizeof(int));
    int required=0;
    for(int i=0;s1[i]!='\0';i++)
    {
        frequency[(unsigned char)s1[i]-'a']++;
        required++;  // required = len(s1)
    }

    int * matched_frequency=calloc(26,sizeof(int));
    
    int left=0,right=0;
    int matched=0;
    while (s2[right]!='\0')
    {
        char c=s2[right];
        int right_index=(unsigned char)c-'a';
        
        // Add character to window
        matched_frequency[right_index]++;
        if(frequency[right_index]>0 && matched_frequency[right_index]<=frequency[right_index])  // s1 mein hai aur zarurat se zyada nahi → matched++
            matched++;

        // Shrink window from left while it's invalid or too large
        while(matched_frequency[right_index] > frequency[right_index] || matched > required)  // s2[right] extra → shrink (matched > required kabhi true nahi hota)
        {
            int left_index=(unsigned char)s2[left]-'a';
            if(frequency[left_index]>0 && matched_frequency[left_index]<=frequency[left_index])  // nikalne wala char matched mein gina tha → matched--
                matched--;
            matched_frequency[left_index]--;
            left++;
        }

        if(matched==required)  // window mein extra nahi + sab mile → exact permutation
        {
            free(frequency);
            free(matched_frequency);
            return true;
        }
        
        right++;
    }
    free(frequency);
    free(matched_frequency);
    return false;
}
```

bool checkInclusion(char* s1, char* s2) 
{
    int left=0 , right=0; 
    int freq_arr[26]={0};
    int matched=0;
    for(int i=0 ; s1[i]!='\0' ;i++)
    {
        freq_arr[(unsigned int)s1[i]-'a']++;
    }

    while(s2[right]!='\0')
    {
        
        int char_index= (unsigned int)s2[right]-'a';
        // Include current 
        if(freq_arr[char_index]>0)  // is char ki abhi zarurat thi → matched++
           matched++;
        freq_arr[char_index]--;  // freq_arr[c] = kitne aur chahiye; < 0 matlab extra

        //Check if current violates condition if yes than reduce window
        while(freq_arr[char_index]<0) //While loop because there can be more char than required of correct ones like if 'ab' is need there can be 'caaaadbbjjabuu'
        {
            int left_char_index=(unsigned int)s2[left]-'a';
            if(freq_arr[left_char_index]>=0)  // >= 0 → ye char extra nahi, matched tha → matched--
                matched--;    
            freq_arr[left_char_index]++;
            left++;
        }
        //Check the result 
        if(matched == strlen(s1))  // Gotcha: strlen har iteration O(m) → total O(n·m)
            return true;

        //Advance
        right++;
    }
    return false;
}
