# 76. Minimum Window Substring
> `s` ki sabse chhoti substring do jisme `t` ke saare characters (duplicates samet) hon; na mile to `""`

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Variable sliding window – minimize, `matched == required`](sliding_window.md) | `freq_t[128]`, `freq_window[128]` (calloc) + `matched` counter | O(m + n) | O(1) (2 × 128 ints) |

**How it works**
- **Soch:** Window valid = `t` ka har char required count mein andar ho. Har baar 128 entries compare karne ki jagah ek counter `matched` rakho: window mein `t` ke kitne chars (duplicates samet) "useful" hain. `matched == required` (= `len(t)`) → window valid.
- **Expand:** `s[right]` `t` mein hai to `freq_window++`; ab bhi `≤ freq_t` hai to useful → `matched++` (extra copies `matched` nahi badhati).
- **Shrink while valid:** `while (matched == required)` — pehle length record (`min_len`, `min_start`), phir `s[left]` nikalo; uska count `freq_t` se neeche gaya to `matched--`. Valid rehte tak chhota karte raho.
- **Result:** Loop ke baad `s + min_start` se `min_len` chars copy + `'\0'`. `min_len` abhi bhi `__INT_MAX__` → `""`.
- **Kyun sahi hai:** Har `right` pe left ko tab tak aage badhaya jab tak window valid hai, to us `right` pe khatam hone wali sabse chhoti valid window record ho jaati hai. `left`, `right` dono sirf aage badhte hain → O(m + n).
- **Dry run:** `s="ADOBECODEBANC", t="ABC"`
  - `r=5`: `ADOBEC` valid → min 6; `A` nikla → invalid
  - `r=10`: `DOBECODEBA` valid → shrink karte `CODEBA` (6, naya min nahi); `C` nikla → invalid
  - `r=12`: `ODEBANC` valid → shrink karte `BANC` (4) record; `B` nikla → invalid → `"BANC"` ✔

**Gotcha:** `__INT_MAX__` GCC-specific built-in macro hai (Clang bhi deta hai), standard C nahi — MSVC pe compile nahi hoga; portable code mein `<limits.h>` ka `INT_MAX`. `freq_window` sirf `t` wale chars ginta hai (`if(freq_t[c] > 0)`), baaki chars ignore.
**vs related:** [567](<567. Permutation in String.md>) mein window size fixed (`len(s1)`) hai aur extra char allowed nahi → exact match; yahan extra chars chalte hain aur window minimize karni hai. [209. Minimum Size Subarray Sum](<../../Arrays/Sliding_Window/209. Minimum Size Subarray Sum.md>) same "shrink while valid, minimize" template hai, bas condition `sum >= target` thi.

<details><summary>Problem statement</summary>

Given two strings s and t of lengths m and n respectively, return the minimum window substring of s such that every character in t (including duplicates) is included in the window. If there is no such substring, return the empty string "".

The testcases will be generated such that the answer is unique.

 

Example 1:

Input: s = "ADOBECODEBANC", t = "ABC"
Output: "BANC"
Explanation: The minimum window substring "BANC" includes 'A', 'B', and 'C' from string t.
Example 2:

Input: s = "a", t = "a"
Output: "a"
Explanation: The entire string s is the minimum window.
Example 3:

Input: s = "a", t = "aa"
Output: ""
Explanation: Both 'a's from t must be included in the window.
Since the largest window of s only has one 'a', return empty string.

</details>

## Code

```c

char* minWindow(char* s, char* t) {
    if (!s || !t || *s == '\0' || *t == '\0') {
        char* empty = malloc(1);  // "" literal nahi → caller free() karega, isliye heap pe
        empty[0] = '\0';
        return empty;
    }
    
    int* freq_t = calloc(128, sizeof(int));  // 128 = poora ASCII (upper + lower case dono)
    int required = 0;
    
    // Count frequency of each character in t
    for(int i = 0; t[i] != '\0'; i++) {
        freq_t[(unsigned char)t[i]]++;
        required++; // Total characters we need to match
    }
    
    int* freq_window = calloc(128, sizeof(int));
    // matched == required → t ke saare chars (duplicates samet) window mein → valid
    int matched = 0; // How many characters from t we've matched
    int left = 0, right = 0;
    int min_len = __INT_MAX__;  // sentinel "koi window nahi mili"; GCC built-in, portable: INT_MAX
    int min_start = 0;  // sirf start + len yaad rakho → substring end mein ek baar banegi
    
    while(s[right] != '\0') {
        char c = s[right];
        
        // Add character to window
        if(freq_t[(unsigned char)c] > 0) {
            freq_window[(unsigned char)c]++;
            // Only count if we haven't exceeded the requirement
            if(freq_window[(unsigned char)c] <= freq_t[(unsigned char)c]) {
                matched++;
            }
        }
        
        // Try to shrink window from left while it's valid
        while(matched == required) {  // valid hai tab tak chhota karo → is right ke liye min window
            // Update minimum window
            if(right - left + 1 < min_len) {
                min_len = right - left + 1;
                min_start = left;
            }
            
            // Remove leftmost character
            char left_c = s[left];
            if(freq_t[(unsigned char)left_c] > 0) {
                freq_window[(unsigned char)left_c]--;
                // Only decrease matched if we go below requirement
                if(freq_window[(unsigned char)left_c] < freq_t[(unsigned char)left_c]) {
                    matched--;
                }
            }
            left++;
        }
        
        right++;
    }
    
    free(freq_t);
    free(freq_window);
    
    // No valid window found
    if(min_len == __INT_MAX__) {
        char* empty = malloc(1);
        empty[0] = '\0';
        return empty;
    }
    
    // Build result
    char* res = malloc(sizeof(char) * (min_len + 1));  // +1 → '\0' ke liye
    for(int i = 0; i < min_len; i++) {
        res[i] = s[min_start + i];  // s[min_start .. min_start+min_len-1] copy
    }
    res[min_len] = '\0';
    
    return res;
}

```
