# 49. Group Anagrams
> Strings ki list mein saare anagrams ko ek-ek group mein daalo

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Hashing – freq signature as key](hashing.md) | `unordered_map<string, vector<string>>` + `str_freq[26]` | O(n·(k + 26)), k = max word length | O(n·k) |

**How it works**
- **Soch:** Do strings anagram hain ⇔ unka 26-letter freq same hai ([242](<242. Valid Anagram.md>)). To freq ko ek string **key** bana do — same key wale saare words ek hi bucket mein.
- **Build key:** Har word ka `str_freq[26]` bharo, phir `key = " " + "c0#c1#...#c25#"`. `#` separator zaroori hai — warna `a=1,b=11` aur `a=11,b=1` dono `"111..."` ban jaate.
- **Group:** `mapp[key].push_back(word)`; end mein map ki har value ek group → `res`.
- **Kyun sahi hai:** Key sirf counts pe depend karti hai, letters ke order pe nahi → saare anagrams same key; separator se encoding unique → non-anagrams alag key. Har word O(k + 26).
- **Dry run:** `["eat","tea","tan","ate","nat","bat"]`
  - `"eat"` → key `" 1#0#0#0#1#...#1#..."` (a, e, t = 1) → naya group
  - `"tea"`, `"ate"` → same counts → same key → `[eat, tea, ate]`
  - `"tan"`, `"nat"` → `[tan, nat]`; `"bat"` → `[bat]` ✔

**Gotcha:** Key ka `" "` se shuru hona harmless hai (sab keys mein same prefix). `""` ka key = 26 zeros → valid, `[[""]]` aata hai. Groups ka order `unordered_map` ke iteration pe depend karta hai — problem "any order" allow karti hai.
**vs related:** [242](<242. Valid Anagram.md>) do strings ka signature compare karta hai; yahan signature hi map key hai. Alternative key `sort(word)` O(k log k) per word hai — count wala key O(k + 26). [451](<451. Sort Characters By Frequency.md>) mein count se output ka order banta hai.

## Code

```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) 
    {
        unordered_map<string,vector<string>> mapp;  // freq signature (key) → us signature wale saare words
        vector<vector<string>>res;

        for(auto &it : strs)
        {
            vector<int>str_freq(26,0);  // har word ka fresh count
            for (auto c: it)
            {
                str_freq[c-'a']++;  // count → letters ka order ignore ho jaata hai
            }

            string key=" ";
            for ( int i=0 ; i< 26;i++)
            {
                key+=to_string(str_freq[i]);  // count ko key mein likho
                key+='#';  // separator → a=1,b=11 aur a=11,b=1 alag keys
            }

            mapp[key].push_back(it);  // same key = anagram → same group
        }    

        for( auto &it : mapp)
        {
            res.push_back(it.second);  // map ki har value ek group
        }
        return res;
    }
};
```
