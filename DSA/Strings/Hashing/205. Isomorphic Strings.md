# 205. Isomorphic Strings
> Check karo ki `s` ke chars ko one-to-one replace karke `t` ban sakta hai ya nahi

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Hashing – two-way char mapping](hashing.md) | `char t_in_s[256]`, `char s_in_t[256]` | O(n) | O(1) (2 × 256) |

**How it works**
- **Soch:** Isomorphic = **one-to-one** mapping `s → t`. Sirf `s→t` map check karna kaafi nahi — do alag `s` chars ek hi `t` char pe map na hon, ye bhi chahiye. To dono directions ka map rakho.
- **Maps:** `t_in_s[c]` = `s` ka char `c` kis `t` char pe gaya; `s_in_t[c]` = `t` ka char `c` kis `s` char se aaya. `0` = abhi unmapped (sentinel).
- **Check + set:** Har `i` pe: `t[i]` pehle se mapped hai par `s[i]` se nahi → false; `s[i]` pehle se mapped hai par `t[i]` pe nahi → false. Phir dono maps set karo (pehle se same ho to overwrite harmless).
- **Kyun sahi hai:** Dono maps consistent rahe → har `s` char ka ek hi image aur har `t` char ka ek hi source → bijection. Ek pass O(n), maps fixed 256.
- **Dry run:** `s="egg", t="add"`
  - `i=0`: `e↔a` dono unmapped → set
  - `i=1`: `g↔d` dono unmapped → set
  - `i=2`: `t_in_s['g']='d'` == `t[2]`, `s_in_t['d']='g'` == `s[2]` → ok → true ✔

**Gotcha:** One-way map fail hota: `s="ab", t="aa"` — `s→t` (`a→a, b→a`) consistent dikhta hai, par `t` ka `a` do chars se aa raha → reverse map (`s_in_t`) hi pakadta hai. Index `char` (signed) hai — constraints ASCII guarantee karte hain, warna non-ASCII pe negative index (UB). `0` sentinel safe hai kyunki `'\0'` string ke andar aata hi nahi.
**vs related:** [242](<242. Valid Anagram.md>) / [49](<49. Group Anagrams.md>) mein sirf counts matter karte hain, position nahi; yahan har position pe char-to-char mapping consistent honi chahiye.

<h2><a href="https://leetcode.com/problems/isomorphic-strings">205. Isomorphic Strings</a></h2><h3>Easy</h3><hr><p>Given two strings <code>s</code> and <code>t</code>, <em>determine if they are isomorphic</em>.</p>

<p>Two strings <code>s</code> and <code>t</code> are isomorphic if the characters in <code>s</code> can be replaced to get <code>t</code>.</p>

<p>All occurrences of a character must be replaced with another character while preserving the order of characters. No two characters may map to the same character, but a character may map to itself.</p>

## Code

```cpp
class Solution {
public:
    bool isIsomorphic(string s, string t) {

        if(s.size() != t.size()) return false;

        char t_in_s[256]={0};  // s ka char → kis t char pe map hua; 0 = abhi unmapped
        char s_in_t[256]={0};  // reverse map: t ka char → kis s char se aaya

        int i=0;

        while(s[i]!='\0')
        {
            if(s_in_t[t[i]] !=0)  // t[i] pehle kisi s char se map ho chuka?
            {
                if(s_in_t[t[i]] != s[i]) return false;  // do alag s chars ek hi t char pe → one-to-one toota
            }
            if(t_in_s[s[i]] !=0 )  // s[i] ka mapping pehle ban chuka?
            {
                if(t_in_s[s[i]] != t[i]) return false;  // s[i] ab alag char pe ja raha → inconsistent
            }
            s_in_t[t[i]] = s[i];  // dono maps set (pehle se same ho to overwrite harmless)
            t_in_s[s[i]] = t[i];
            i++;
        }
        return true;
    }
};
```
