# 451. Sort Characters By Frequency
> String ke chars ko frequency ke decreasing order mein likho (same chars ek saath)

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Hashing – freq map + bucket by count](hashing.md) | `unordered_map<char,int>` + `vector<vector<char>> bucket(n+1)` | O(n) | O(n) |

**How it works**
- **Soch:** Pehle har char ka count chahiye (hash map). Phir chars ko count ke decreasing order mein likhna hai. Sort ki zarurat nahi — count hamesha `1..n` mein hai, to count ko hi **index** bana do (bucket sort).
- **Count:** `freq[ch]++` har char ke liye (`'A'` aur `'a'` alag).
- **Bucket:** `bucket[fr]` = wo saare chars jinka count `fr` hai. Size `n+1` kyunki max count `n` ho sakta hai.
- **Build:** `i = n` se `1` tak neeche; `bucket[i]` ke har `ch` ke liye `res.append(i, ch)` — char `i` baar, ek saath.
- **Approach 2/3 (neeche `/* */` block mein "Approach 1" / "Approach 2"):** (2) `freq[128]` + poori string ko `sort` custom comparator se — count zyada pehle, tie pe `a<b` taaki same chars ek saath rahein → O(n log n). (3) map → `vector<pair<char,int>>`, pairs ko count se sort, phir `append(fq, ch)` → O(n + d log d), d = distinct chars.
- **Kyun sahi hai:** Bucket index = count, aur loop bade index se chhote ki taraf → zyada frequent chars pehle. Har char ek hi bucket mein → uska poora block ek saath append. Count O(n) + buckets O(n) + output O(n).
- **Dry run:** `"tree"`
  - freq: `t=1, r=1, e=2`
  - `bucket[2]={e}`, `bucket[1]={t,r}` (order map pe depend)
  - `i=2` → `"ee"`, `i=1` → `"eert"` ✔

**Gotcha:** Approach 2 mein tie-break `a<b` zaroori hai — sirf `freq[a]>freq[b]` ho to same-count chars equal maane jaate hain aur `sort` unhe mix kar sakta hai (`"cacaca"` jaisa galat output). Same-count chars ka order `unordered_map` pe depend karta hai — "any answer" allowed hai.

class Solution {
public:
    string frequencySort(string s) 
    {
        unordered_map<char,int> freq;
        //Store frequency of each character 
        for (auto ch : s) freq[ch]++;
        //Create a bucket vector of vector of char , and fill it with map data.

        vector<vector <char>> bucket(s.size()+1);  // bucket[f] = jin chars ka count f; max count n → size n+1
        for( auto [ch, fr]: freq) bucket[fr].push_back(ch);  // count hi index → sort ki zarurat nahi

        string res;
        for (int i = bucket.size()-1; i>=1; i-- )  // bade count se chhote → decreasing freq; bucket[0] khaali
        {
            for(auto ch : bucket[i])
            {
                res.append(i,ch);  // char i baar ek saath → same chars grouped
            }
        }

        return res;


    }
};
