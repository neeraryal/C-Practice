# 242. Valid Anagram
> Check karo ki `t` sirf `s` ke letters ko rearrange karke bana hai ya nahi

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Hashing – freq count + cancel](hashing.md) | `int freq[26]` | O(n) | O(1) (26 ints) |

**How it works**
- **Soch:** Anagram = same letters, same counts — order matter nahi karta. Sort karke compare O(n log n) hota; sirf 26 lowercase letters hain to seedha count array se O(n).
- **Count + cancel:** Length alag → turant `false`. Ek hi loop mein `s[i]` ka `freq++` aur `t[i]` ka `freq--` — dono strings ek doosre ko cancel karti hain.
- **Check:** End mein saare 26 slots 0 → anagram; koi bhi non-zero → kisi letter ka count mismatch.
- **Kyun sahi hai:** `freq[c]` = (`s` mein `c` ka count) − (`t` mein `c` ka count). Sab zero ⇔ har letter ka count barabar. Ek pass + 26 check → O(n), extra space fixed.
- **Dry run:** `s="anagram", t="nagaram"`
  - `i=0`: `a`++, `n`-- → `a=1, n=-1`
  - `i=1`: `n`++, `a`-- → dono wapas 0
  - End tak har letter cancel (dono mein `a=3, n=1, g=1, r=1, m=1`) → 26 zeros → true ✔

**Gotcha:** Length check pehle zaroori hai — loop sirf `s` ke `'\0'` tak chalta hai, `t` ki length alag se kahin check nahi hoti. `- 'a'` sirf lowercase pe valid; Unicode follow-up ke liye `unordered_map` lo.
**vs related:** [49](<49. Group Anagrams.md>) mein yahi freq signature hash map ka key ban jaata hai (do strings nahi, poore groups). [567](<../Sliding_Window/567. Permutation in String.md>) mein same `++/--` cancel ek fixed sliding window ke andar hota hai.

## Code

```cpp
class Solution {
public:
    bool isAnagram(string s, string t) 
    {
        int s_len = s.size();
        int t_len = t.size();

        if(s_len != t_len) return false;  // length alag → anagram nahi; loop sirf s ke '\0' tak chalta hai

        int freq[26]={0};  // sirf 26 lowercase letters → hash map ki jagah fixed array
        int i=0;
        while(s[i] != '\0')
        {
            freq[(unsigned int)s[i]-'a']++;  // s ka char → count +1
            freq[(unsigned int)t[i]-'a']--;  // t ka char → -1 (same letter ho to cancel)
            i++;   
        }
        i=0;
        while(i<26)
        {
            if(freq[i] !=0) return false;  // kisi letter ka count mismatch → anagram nahi
            i++;
        }
        return true;
    }
};
```
