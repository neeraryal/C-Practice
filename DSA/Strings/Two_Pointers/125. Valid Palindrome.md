# 125. Valid Palindrome
> Sirf letters/digits lo (case ignore) — string palindrome hai ya nahi?

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Two Pointers – opposite ends, skip junk](two_pointers.md) | Do indices, koi cleaned string nahi | O(n) | O(1) |

**How it works**
- **Soch:** Palindrome = pehla char last se, doosra second-last se... match. Cleaned string (lowercase + sirf alnum) banane ki jagah original pe hi do pointers chalao aur faltu chars skip karo → O(1) space.
- **Skip:** `left` aage badhao jab tak alnum na mile; `right` peeche jab tak alnum na mile. Dono skip loops mein bhi `left<right` guard.
- **Compare:** Dono ko `get_lower_case` → alag → `false`. Same → `left++`, `right--`.
- **Kyun sahi hai:** Har step cleaned string ke i-th aur (last−i)-th char ko compare karta hai; pointers milte hi saare pairs check ho gaye. Har index ek hi baar → O(n).
- **Dry run:** `"A man, a plan, a canal: Panama"`
  - `'A'` vs last `'a'` → lowercase same → dono andar
  - `left` pe `' '` skip → `'m'`; `right` → `'m'` → match
  - `,` `:` aur spaces skip hote rahte → pointers beech mein milte → true ✔

**Gotcha:** Skip loops mein `left<right` na ho to `".,"` jaise all-symbol string pe pointers ek doosre ko cross karke aage nikal jaate. Digits bhi alnum hain — `"0P"` → false (`'0'` vs `'p'`). `ch+32` sirf `'A'..'Z'` pe lagta hai.
**vs related:** [844](<844. Backspace String Compare.md>) mein bhi chars skip hote hain par do **alag strings** pe, right se left. [5](<5. Longest Palindromic Substring.md>) mein pointers center se **bahar** expand karte hain.

## Code

```cpp
class Solution {
public:
    bool check_is_alnum(char ch)
    {
        if(ch>= 'a' && ch<='z')
            return true;
        if(ch>= 'A' && ch<='Z')
            return true;
        if(ch>='0' && ch<='9')
            return true;
        
        return false;
    }

    char get_lower_case(char ch)
    {
        if(ch>='A' && ch <='Z')
        {
            return ch+32;  // ASCII mein 'A'(65) aur 'a'(97) ka gap 32
        }
        return ch;
    }

    bool isPalindrome(string s) 
    {
        int left = 0 , right = s.size()-1;  // dono ends se andar ki taraf
        while (left<right)  // pointers mile → saare pairs check ho gaye
        {
            while(left<right && !check_is_alnum(s[left])) left++;  // faltu char skip; left<right guard → ".," pe cross nahi
            while(left<right && !check_is_alnum(s[right])) right--;  // right side ka faltu char skip

            if(get_lower_case(s[left]) != get_lower_case(s[right]))  // case ignore karke compare
                return false;
            
            left++;  // pair match → dono pointers andar
            right--;
        }
        
        return true;
    }
};
```
