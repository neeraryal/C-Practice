# 844. Backspace String Compare
> Dono strings mein `#` = backspace; type karne ke baad dono same bante hain kya?

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Two Pointers – reverse scan with skip count](two_pointers.md) | Har string pe ek index, koi extra buffer nahi | O(n + m) | O(1) |

**How it works**
- **Soch:** `#` apne *left* wale char ko mitata hai, to right se padho — `#` pehle milta hai aur pata rehta hai kitne chars skip karne hain. Dono strings ke end pe ek-ek pointer, final string banaye bina char-by-char compare.
- **Skip (`get_valid_index`):** Right se chalo; `#` → `count++`; normal char aur `count > 0` → ye mit gaya, `count--`; `count == 0` → yahi agla bachne wala char. Kuch na bache to `-1`.
- **Compare:** Dono ka valid index lo. Dono `-1` → true; sirf ek `-1` → false; chars alag → false. Match pe dono pointers valid index ke **ek peeche** (`i-1`, `j-1`).
- **Kyun sahi hai:** Har round dono typed strings ka agla char (right se) deta hai, to ye exactly final strings ka comparison hai. Har index ek hi baar visit hota hai → O(n + m), O(1) space.
- **Dry run:** `s="ab#c", t="ad#c"` (fix `s_i=i-1` ke saath)
  - `i=3 'c'`, `j=3 'c'` → match
  - `s`: `#` → count 1, `b` mita → `i=0 'a'`; `t` same → `j=0 'a'` → match
  - dono `-1` → true ✔

**Gotcha:** Loop `||` pe chalta hai, `&&` pe nahi — ek string khatam hone ke baad doosri mein bache chars bhi check hone chahiye (`s="a", t="ba"` → false). `count` har call mein 0 se — pichla call valid char pe ruka tha, koi `#` pending nahi.
**vs related:** [26](<../../Arrays/Two_Pointers/26. Remove Duplicates from Sorted Array.md>) jaise read/write pointer se string ko in-place "type" bhi kar sakte ho (`#` pe write pointer peeche) — par wo input badalta hai; reverse scan input ko touch nahi karta.
**⚠ Known bug:** `s_i=i--;` post-decrement hai → `s_i` ko `i` hi milta hai (decrement local `i` pe hota hai jo phenk diya jaata hai), to `s` ka pointer matched char pe atka rehta hai. Example 1 `"ab#c","ad#c"` pe `false` aata hai (expected `true`); `s="a", t="a"` pe bhi `false`. Fix: `s_i=i-1;`.

<details><summary>Problem statement</summary>

Given two strings s and t, return true if they are equal when both are typed into empty text editors. '#' means a backspace character.

Note that after backspacing an empty text, the text will continue empty.

 

Example 1:

Input: s = "ab#c", t = "ad#c"
Output: true
Explanation: Both s and t become "ac".
Example 2:

Input: s = "ab##", t = "c#d#"
Output: true
Explanation: Both s and t become "".
Example 3:

Input: s = "a#c", t = "b"
Output: false
Explanation: s becomes "c" while t becomes "b".

</details>

## Code

```c

int get_valid_index(char * s, int index) //Will reutn the valid index after processign # and if not a avlid index the return -1
{
    int count=0;  // pending backspaces — left ke kitne chars mitane hain
    while(index >=0)
    {
        if(s[index]=='#')  // backspace → left ka ek char skip karna padega
        {
            count++;
        }
        else 
        {
            if (count>0)
            {
                count--;  // ye char backspace se mit gaya
            }
            else{
                return index;  // koi # pending nahi → ye char final string mein bachega
            }
        }
        index--;
    }
    return -1;  // saare chars mit gaye → empty
}
 
bool backspaceCompare(char* s, char* t)
{
    int s_i= strlen(s)-1;  // right se scan → # ka asar pehle pata chalta hai
    int t_i= strlen(t)-1;
 
    while(s_i>=0 || t_i>=0)  // || → ek string bachi ho to bhi check (shayad sab # se mite)
    {
        int i = get_valid_index(s,s_i); 
        int j = get_valid_index(t,t_i);
 
        if(i==-1 && j==-1 ) return true; // If both reached end of string i.e. same NULL string 
        if (i == -1 || j == -1)return false; // If any one reach NULL string but other has a valid index to process, not same return false

        if(s[i]!=t[j]) // If valid index value is not same , return fasle 
            return false;
 
        // ⚠ post-decrement → s_i = i hi (matched char pe atka); s_i=i-1 chahiye
        s_i=i--; //Update pointer to next index of valid index received, not s_i++; 
        t_i=j-1; //Update pointer to next index of valid index received, not t_ii++; 
    }
    return true;

}


```
