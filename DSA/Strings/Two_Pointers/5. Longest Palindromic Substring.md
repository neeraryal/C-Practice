# 5. Longest Palindromic Substring
> String ka sabse lamba palindromic substring return karo

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Two Pointers – expand around center](two_pointers.md) | `start` / `end` indices, `substr` at the end | O(n²) | O(1) extra |

**How it works**
- **Soch:** Har palindrome ka ek center hota hai — odd length ka ek char (`"aba"`), even length ka do chars ke beech (`"abba"`). Kul 2n−1 centers; har center se pointers **bahar** expand karo jab tak chars match karein.
- **Expand:** `expand_palindrome(s, a, b)`: jab tak `s[a]==s[b]` → `a--`, `b++`. Loop rukne pe `a`, `b` ek-ek step bahar hain → length `b-a-1`.
- **Har `i` pe:** `len1 = expand(i, i)` (odd), `len2 = expand(i, i+1)` (even). Bada mila to `start = i-(len-1)/2`, `end = i+len/2`. Index math: odd `len=3` at `i=1` → `[0,2]`; even `len=2` at `i=1` (center 1|2) → `[1,2]` — even pe `(len-1)/2` left half ko ek kam rakhta hai.
- **Kyun sahi hai:** Longest palindrome ka center bhi in 2n−1 centers mein se ek hai, aur wahan se expand karke wo poora mil jaata hai. Har center O(n) expand → O(n²); extra sirf indices.
- **Dry run:** `"babad"`
  - `i=0`: `len1=1` → `start=end=0`, `res_len=1`
  - `i=1`: center `'a'` → `"bab"`, `len1=3` → `start=1-1=0`, `end=1+1=2`
  - `i=2`: `"aba"` bhi 3, `>` strict → update nahi → `substr(0,3)="bab"` ✔

**Gotcha:** `s.size() >= 1` hai to `res_len` kam se kam 1 hoga — initial `start=-1` kabhi `substr` tak nahi pahunchta. Even center `i+1 == n` pe `b<s.size()` turant fail → `len2=0`, safe. `plaindrome_length` unused hai (nit).
**vs related:** [125](<125. Valid Palindrome.md>) ek *given* string ko ends se andar check karta hai; yahan har center se **bahar** expand → saare palindromes cover. [234](<../../Linked_List/Fast_Slow/234. Palindrome Linked List.md>) mein list pe random access nahi → middle dhoondh ke half reverse.
**Better approach:** Manacher's algorithm O(n) — pichle palindrome ke mirror center ka radius reuse karke har center ka expand amortized O(1).

## Code

```cpp
class Solution {
public:
    int expand_palindrome(string &s, int a, int b )
    {
        int plaindrome_length=0;  // unused (nit)

        while(a>=0 && b<s.size() && s[a]==s[b])  // bounds ke andar aur chars match → palindrome aur bada
        {
            a--;  // center se bahar expand
            b++;
        }
        return b-a-1;  // loop ke baad a, b ek-ek step bahar → length = b-a-1
    }

    string longestPalindrome(string s) 
    {
        int res_len=0;
        string res;
        int start =-1, end= -1;
        for (int i=0 ; i<s.size();i++)
        {
            int len1 = expand_palindrome(s, i, i);  // odd length: center ek char
            int len2 = expand_palindrome(s, i ,i+1);  // even length: center i aur i+1 ke beech

            int len_max= max(len1, len2);
            if(len_max>res_len)  // strict > → same length pe pehla palindrome rehta hai
            {
                start = i-(len_max-1)/2;  // left half; even len pe (len-1)/2 ek kam → center i|i+1 sahi
                end= i+(len_max/2);  // right half: 3@i=1 → [0,2], 2@i=1 → [1,2]
                res_len= len_max;
            }
        }
        res=s.substr(start, (end - start +1));  // s.size()>=1 → start kabhi -1 nahi rehta
        return res; 
    }
};
```
