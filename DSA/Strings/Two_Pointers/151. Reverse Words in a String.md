# 151. Reverse Words in a String
> Words ka order ulta karo, beech mein sirf ek space, aage-peeche koi space nahi

| Pattern | Data structure | Time | Space |
|---|---|---|---|
| [Two Pointers – right se scan, word boundaries](two_pointers.md) | `left` / `right` indices + `string res` | O(n) | O(n) (output) |

**How it works**
- **Soch:** Words ulte order mein chahiye → string ko **right se** padho; jo word pehle milega wahi output mein pehle jaayega. `right` = current word ka last char, `left` = scan pointer jo word ki shuruaat dhoondhta hai.
- **Space:** `s[left]==' '` → `left--` aur `right=left` — `right` agle possible word ke end pe aa jaata hai (extra spaces aise hi skip).
- **Word start:** `s[left-1]==' '` (ya `left==0`) → `left` word ka pehla char hai → `res` khaali nahi to pehle `' '`, phir `s[left..right]` append.
- **Kyun sahi hai:** Har word apne start pe exactly ek baar append hota hai, right-to-left order mein. Separator sirf words ke *beech* lagta hai (`!res.empty()`), to leading/trailing/multiple spaces output mein nahi aate. Har char ek baar → O(n).
- **Dry run:** `"  hello world  "`
  - `left=14,13` spaces → `left=right=12`
  - `left=8`: `s[7]==' '` → append `"world"`
  - `left=7` space → `right=6`; `left=2`: `s[1]==' '` → `' '` + `"hello"` → `"world hello"` ✔

**Gotcha:** `left==0` ka alag branch zaroori hai — wahan `s[left-1]` = `s[-1]` hota, isliye pehli condition mein `left>0 &&` guard hai. Spaces edge cases: `"  a  "` → `"a"`, `"a good   example"` → `"example good a"`.
**vs related:** [125](<125. Valid Palindrome.md>) mein pointers dono ends se andar aate hain; yahan dono right se left ek hi direction mein (`right` word end yaad rakhta hai, `left` scan). [844](<844. Backspace String Compare.md>) bhi right se scan karta hai.
**Better approach:** Follow-up (in-place, O(1) extra): poori string reverse karo, phir har word ko alag se reverse, aur read/write pointer se extra spaces compact karo.

## Code

```cpp
class Solution {
public:
    string reverseWords(string s) 
    {
        string res="";
        int right= s.size()-1,left= s.size()-1;  // right se scan → jo word pehle mile wahi output mein pehle
        while(left>=0)
        {
            if(s[left]==' ')  // space → word ka hissa nahi
            {
                left--;
                right=left;  // right = agle possible word ka last char (extra spaces skip)
                continue;
            }
            if(left>0 && s[left-1]==' ')  // pichla char space → left word ka pehla char; left>0 → s[-1] nahi
            {
                if(!res.empty())  // separator sirf words ke beech → leading/trailing space nahi
                {
                    res.push_back(' ');
                }
                res.append(s,left,right-left+1);  // s[left..right] = poora word
                right=left;
            }
            else if (left==0 && s[left]!=' ')  // string ka pehla word — uske pehle space nahi hota
            {
                if(!res.empty())
                {
                    res.push_back(' ');
                }
                res.append(s,left,right-left+1);
                right=left;
            }
            left--;  // scan aage (left ki taraf)
        }    
        return res;
    }
};
```
